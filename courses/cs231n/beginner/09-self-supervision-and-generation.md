# 09 自监督学习与生成模型

> 本单元分清两件事：训练目标从哪里来，以及模型最后用来提取表示还是生成样本。这里只建立入口；ELBO、对比损失、采样算法的完整推导在课程正文。

## 1. 自监督不等于没有目标

监督学习常使用人工类别、框或像素标签。自监督学习从数据本身构造目标，但仍要计算损失、反向传播和更新参数。

例如把原图的一部分藏起来，原始内容仍可作为预测答案。模型训练时没有直接看到答案，不等于训练程序无法知道答案。

## 2. 对比学习：比较两个视图的表示

对同一张图像做两次合适的增强，得到 A、B，再通过网络：

$$z_A=f(A),\qquad z_B=f(B).$$

f 是特征提取网络，z 是特征向量。一类常见方法使同图视图的表示相近，并相对地区分其他图像的表示。正样本对、负样本是训练关系，不是“正确图片”和“错误图片”。

如果只要求所有向量接近，网络可以让任何图像都输出零向量。这样的**表示坍塌**满足了粗糙要求，却丢失区分能力。对比方法和其他自监督方法需要各自的机制避免退化。

增强要符合任务。如果裁剪完全移除了原来相关内容，或翻转改变了需要识别的方向，就不能无条件要求表示相同。并非所有自监督方法都需要显式负样本。

## 3. 遮挡重建：用图像自己提供答案

以 MAE（Masked Autoencoder，掩码自编码器）为例：

```text
完整图像 → 分块 → 遮住部分块 → 根据可见内容预测被遮住部分
    └────────────────────→ 用原始内容计算重建误差
```

损失作用于预测内容与已知目标的差异。具体目标和归一化方式取决于方法，不能把所有遮挡方法都当作完全相同的像素 MSE。

自监督预训练后，可以使用特征网络进行下游分类、检测或分割，再用任务数据微调。预训练任务做得好仍需通过下游评估确认价值。

## 4. 生成：同一个条件为什么可以有很多正确结果？

分类通常从图像输出类别；生成模型产生数据样本，例如 `随机变量 + 文字条件 → 图像`。

“草地上的猫”允许不同姿态、毛色、背景。随机变量使模型能够生成多种结果。训练关注数据分布的结构，而不是为每句话指定唯一图片。

生成与自监督不是互斥分类：一种方法可以用自监督目标训练，并服务于生成或表示学习。

## 5. 自回归：先学每一步的条件概率

把样本拆成有顺序的单位 x₁,…,x_T，用概率链式法则：

$$p(x_1,\ldots,x_T)=\prod_{t=1}^{T}p(x_t\mid x_{<t}).$$

x_<t 表示当前位置之前的内容。训练时学习已知前缀下的下一个单位；生成时逐步采样，把刚生成的结果加入前缀。

例如用简化的三步概率 0.5、0.8、0.25，某个序列概率是 0.1。真实模型的各条件概率依赖具体前缀，不能把所有位置当作独立事件。

生成的单位可以是文本 token，也可以是离散化后的图像表示。因果掩码的目的，是训练预测时不要偷看答案。

## 6. 从自编码器理解 VAE

普通自编码器：`图像 x → 编码器 → 潜在表示 z → 解码器 → 重建 x̂`。

能重建训练图像，不意味着随便给一个随机向量都能得到合理图像。VAE（变分自编码器）给潜变量建立概率模型，并约束编码分布与先验的关系。

常见编码器输出均值 μ 和标准差 σ，借助重参数化采样：

$$\epsilon\sim\mathcal N(0,I),\qquad z=\mu+\sigma\odot\epsilon.$$

μ、σ、ε 都是向量；⊙ 为逐元素乘法。编码器参数通过 μ、σ 影响 z，使训练能够传播梯度。

最小化的负 ELBO 可以理解为：

$$L=\underbrace{-\mathbb E_{q(z\mid x)}[\log p(x\mid z)]}_{重建负对数似然}
+\underbrace{\operatorname{KL}(q(z\mid x)\Vert p(z))}_{分布约束}.$$

这里 q 是编码器给出的分布，p(z) 是先验，p(x∣z) 是解码器的概率模型。重建项具体长什么样取决于输出分布假设，不永远等于未加权像素平方误差。

第一遍只抓住“重建要合理，潜在分布也要与先验相容”。生成时从先验采样 z，再解码，不需要先输入一张真实图像。

## 7. GAN：生成器与判别器提供不同训练信号

- 生成器 G：把随机输入变成样本。
- 判别器 D：学习区分真实数据与生成样本。

生成器通过与判别器有关的目标学习，让生成结果更难区分。双方目标不同，通常交替更新，不是两者一起最小化同一个普通分类误差。

训练可能不稳定，也可能出现模式坍塌：生成结果只覆盖少数类型。判别器分数本身不是可靠的完整质量评估。

## 8. 扩散：先理解训练与生成方向

常见扩散思路是从真实数据构造不同噪声程度的输入，让模型预测恢复所需的信息。目标可能是噪声、干净样本或其他参数化，需看具体方法。

```text
训练构造：数据 → 加噪 → 带噪输入，目标由已知数据和噪声得到
生成采样：新噪声 → 反复使用模型与采样规则 → 数据样本
```

生成不是从随机噪声里找回一张唯一预埋的原图，而是根据学到的分布产生样本。

## 9. 本课程第十四讲的重点：Rectified Flow

课程主要用流匹配的路径与速度讲解这部分；下面固定使用**t=0 是数据，t=1 是噪声**的约定。

$$x_t=(1-t)x+t z,\qquad \frac{dx_t}{dt}=z-x.$$

| 量 | 本节含义 |
|---|---|
| x | 已知真实数据 |
| z | 采样的噪声 |
| t | 0 到 1 的连续时间 |
| x_t | 这条插值路径上的位置 |
| v_θ(x_t,t) | 网络预测的速度 |

训练时可以比较 `v_θ(x_t,t)` 与 `z−x`。生成时不知道最终 x，从噪声端开始，用学到的速度场让 t 从 1 走向 0。

为检查方向，用一个**已知路径的标量算例**：x=2、z=10，t=0.5 时 x_t=6，路径速度为 8。若 Δt=−0.1，沿这条已知路径做一步更新，得到 `6+(−0.1)×8=5.2`，确实向数据端靠近。

这个例子只解释时间符号；真实生成时不能拿未知的真实 x 计算速度，必须使用模型预测。一个位置的学习速度场也不能简单等同于每一条训练样本路径的速度。

传统扩散与流匹配有联系，但噪声预测和速度预测的目标、时间约定不能混用。

## 10. 四类方法对照

| 方法 | 训练时主要学习 | 生成时怎样做 |
|---|---|---|
| 自回归 | 给定前缀的条件概率 | 按顺序采样 |
| VAE | 概率重建与潜分布约束 | 从先验采样再解码 |
| GAN | 通过判别器信号改善生成器 | 噪声经生成器映射 |
| Flow Matching | 指定路径上的速度目标 | 从噪声端积分速度场 |

## 复习时记住

**先问目标从哪里来，再问模型预测什么，最后区分训练与生成怎样使用它。** 只记“都能生成图片”会把完全不同的损失与采样过程混在一起。
