# 10 视频、三维、语言、行动与完整课程地图

> 本单元把已经认识的向量、网络和训练目标接到后续主题。这里完成入门路线，不把概念导览写成已深入掌握全部课程。

## 1. 视频比图像多了一条时间轴

从视频抽取 8 帧，每帧 RGB、32×32，一种单视频布局是 `8×3×32×32`：依次为帧数、通道、高、宽。其他布局会调换轴，先看定义。

“杯子在桌上 → 手接触杯子 → 杯子升起”与反过来的顺序，可能分别是拿起、放下。只看静态对象不够。

一种方法是逐帧提取 64 维特征，得到 `8×64`，再使用序列模型组合时间信息。直接平均会丢失顺序：同一组向量换顺序，平均值不变。

## 2. RNN：当前输入加上历史状态

$$h_t=f(h_{t-1},x_t).$$

x_t 为当前输入，h_(t−1) 为之前的状态，h_t 为更新后的状态。相同更新规则跨时间重复使用，反向时共享参数的梯度也要沿时间累加。

LSTM 通过门控控制信息的保存、更新和输出，帮助处理长期依赖；不保证永远记住全部历史。公式与 BPTT 见[第七章](../notes/07-recurrent-networks.md)。

视频也可使用时间注意力，或同时覆盖时间、高、宽的 3D 卷积。视频里的 `3×3×3` 核可能表示连续 3 帧、每帧一个 3×3 窗口，输入通道仍是另外的轴。它不是因为 RGB 有三个颜色通道才叫 3D。

## 3. 三维视觉：投影会丢失深度信息

图像位置通常只需要 `(u,v)` 两个坐标，而空间点需要 `(x,y,z)`。三维投影到二维时会丢失信息：近处的小物体与远处的大物体，可能在图像上占据相近大小。

三维视觉关注深度、位置姿态、形状重建与新视角等问题。

| 表示 | 存什么 | 直觉 |
|---|---|---|
| 点云 | N 个空间点，坐标为 N×3 | 用点描出表面 |
| 网格 | 顶点和面片连接 | 用小三角形拼表面 |
| 体素 | 三维小格子的信息 | 三维版本的规则格子 |
| 隐式函数 | 坐标到占据、距离等量的映射 | 查询一个位置得到形状信息 |

点云的 3 是空间坐标，图像的 3 常为 RGB。点列表重排不应改变对象身份，这与规则图像网格的处理方式不同。NeRF、PointNet 等细节在[第十五章](../notes/15-3d-vision.md)。

## 4. CLIP：把图像与文字映射到可比较的表示

```text
图像 → 图像编码器 → 图像向量
文字 → 文本编码器 → 文字向量
```

使用配对图文训练，使正确配对相对更匹配。一张图像可与“猫的照片”“狗的照片”等候选文字比较相似度，再选择较匹配的描述。

这些是学到的特征相似度，不是原始像素与文字编码直接相等。图文匹配也不自动等于能聊天。

生成式视觉语言模型通常把视觉特征经过连接模块交给语言模型，再结合用户问题生成回答。回答流畅不保证细节得到图像支持，需要另外评估。详细区别见[第十六章](../notes/16-vision-language.md)。

## 5. 机器人：动作会改变下一次看到的环境

```text
观察 → 策略选择动作 → 执行动作 → 环境变化 → 再观察
```

这是闭环。拿杯子时，如果杯子滑动，机器人需要根据新观察调整，而不是只依靠最开始的一张图像。

最简单的策略写为 `a=π(o)`：o 是观察，π 是策略，a 是动作。现实中还可能依赖历史、目标和内部状态。

**行为克隆**使用专家的“观察—动作”示范，像监督学习一样拟合动作。小错误会改变下一步遇到的状态，因此单步准确不保证整个任务成功。

**强化学习**根据动作产生的回报学习，关注长期效果。一种累计回报定义为：

$$R=\sum_{t=0}^{T}\gamma^t r_t.$$

r_t 是第 t 步奖励，γ 是折扣因子。行为克隆参考专家怎么做，强化学习根据行为后果优化；二者可以组合。

视觉—语言—动作模型把观察、文字指令、机器人状态共同用于动作预测，但动作仍需符合具体机器人的控制接口与身体约束。详见[第十七章](../notes/17-robot-learning.md)。

## 6. 分布式训练：资源怎样支持这些模型？

数据并行的一种直观安排：两块 GPU 保存相同模型，各处理一半批次，计算各自梯度后汇总，再一致地更新。

若两边各有 32 个样本，分别计算平均梯度为 g₁、g₂，全局平均为 `(g₁+g₂)/2`。若样本数不同，需按样本数加权，不能机械平均局部均值。

模型本身放不下时，还可能拆分参数、优化器状态或计算阶段。这些方法主要解决执行和存储问题，不保证更高预测准确率。深入阅读见[第十一章](../notes/11-distributed-training.md)。

## 7. 以人为中心：指标要放回真实用途

平均准确率高，也可能掩盖某些群体或条件的差异。构造一个例子：900 个常见条件样本准确率 99%，100 个其他条件样本准确率 60%，整体为：

$$\frac{900\times0.99+100\times0.60}{1000}=95.1\%.$$

总体数字看起来高，却没有消除后一组的问题。这个例子只是说明加权平均，不是课程报告的实测结果。

理解系统时，还要问数据覆盖哪些条件、错误会如何影响实际任务，以及人怎样理解或修正模型行为。课程第十八章把技术与人的需求连接起来；其来源仍是视频画面及可见字幕抽查，不是完整逐句转录。

## 9. 接下来怎样复习？

先回到数组形状，再手算一次预测、损失和更新，然后追踪完整 CNN，最后手算一次注意力。遇到新模型，依次找**输入、计算、输出、损失**，不要把记住缩写当作理解。
