## 1. 计算机接收到什么？

图片可以用数字数组表示。以常见的 8 位灰度图为例，每个像素用一个数表示亮度，通常 0 是黑色、255 是白色，中间的数表示不同灰度。

一个 2 × 2 的灰度图可以写成：

```text
  0  255
128   64
```

它只有 4 个像素。这里的矩阵就是按行、列排列的数字。

对于 RGB 彩色图，每个像素包含红、绿、蓝三个通道。例如在常见的 8 位表示中，(255, 0, 0) 表示红色。

因此，一张高 32、宽 32 的 RGB 图片包含 32 × 32 × 3 = 3072 个通道数值。用“高、宽、通道”的顺序描述，其形状为 (32, 32, 3)。其他软件也可能采用不同的维度顺序。

### 同一个“像素”，为什么有时说三个数？

可以把 RGB 图像想成三张对齐的亮度表：红通道、绿通道、蓝通道。一个空间位置对应三张表中的三个值。**32×32 是空间像素数量，32×32×3 是通道数值数量。** 后续卷积中的“通道”不一定还是红绿蓝，也可以是模型学出来的不同特征。

“一批图片”再增加一个轴。例如 64 张 32×32 RGB 图像，可以存成 `(64, 32, 32, 3)`；若展平每张图，则成为 `(64, 3072)`。64 始终是样本数，不能把不同图片混成同一个样本。

## 2. 图像分类在做什么？

图像分类（Image Classification）把图片映射到预先定义的类别，例如“猫”或“狗”。

人看到耳朵、毛发和轮廓，计算机首先接收到的是数字。模型需要从带标签的训练样本中学到有用的规律，再对没有见过的图片作出判断。

“训练”是利用样本调整模型参数；“预测”是用学到的参数处理输入。模型输出可以是各类别的分数，但分数是否能解释成概率，要看具体模型与处理方法。

## 3. 为什么不直接比较两张图片的数字？

同一只猫换个位置、换种光照，很多像素数值就会改变，但类别仍然是猫。我们希望模型学到对分类有用的特征，并减少无关变化的影响。

## 4. 例子说明

- 高 64、宽 64 的 RGB 图片包含 64 × 64 × 3 = 12288 个通道数值。
- 同一只猫移动位置会改变像素数组，但它的类别仍然是猫。
- 训练利用样本调整模型参数，预测利用学到的参数处理输入。
