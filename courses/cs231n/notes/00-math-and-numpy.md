# 预备工具箱：读懂公式、形状与 NumPy

> **使用方式**：遇到不会的符号时来查，不要求先背完。本文是原创基础补充，不是新增的一讲，也不改变官方课程顺序。

## 1. 标量、向量、矩阵、张量

| 名称 | 可以怎样理解 | 例子与形状 |
|---|---|---|
| 标量 | 一个数 | 损失 `0.5`，NumPy 形状 `()` |
| 向量 | 按顺序排列的一组数 | `[2, 3, 5]`，形状 `(3,)` |
| 矩阵 | 有行和列的数表 | 两个样本各三个特征，形状 `(2, 3)` |
| 张量 | 多个轴上的数值数组 | 一批 RGB 图片可为 `(N, 3, H, W)` |

**“100 维向量”表示有 100 个分量；NumPy 的 `ndim=1` 表示数组只有一个轴。** 这两个“维”在不同语境里数的是不同东西。

例如 `X.shape == (64, 1000)`：有 64 行，每行一个样本；每个样本用 1000 个特征表示。它是二维数组，每行对应一个 1000 维向量。

图像展平只是改变排列形式。32×32×3 个数排成 3072 个数，不会自动提取出“眼睛”“轮子”等语义特征。

## 2. 下标、求和与范数

`x_i` 通常表示向量第 i 个元素；`X_ij` 表示矩阵第 i 行、第 j 列。具体含义由本章定义，有时 `x_i` 也表示第 i 个样本，应连同形状一起看。

$$\sum_{j=1}^{3}x_j=x_1+x_2+x_3.$$

**Σ 是“把一组项加起来”，不是需要额外学习的新运算。** 例如 x=[2,−1,3]，则 Σx_j=4。

范数把一组数概括成一个大小：

$$\|x\|_1=|2|+|-1|+|3|=6,$$
$$\|x\|_2=\sqrt{2^2+(-1)^2+3^2}=\sqrt{14}.$$

`||x−z||` 则先逐位置做差，再求差向量的大小。对距离而言，**L2 距离与 L2 距离的平方不同**；只是对非负数排序时，平方与开根号不改变顺序。

截图中常见的 `p_m^(k)`，可读为“第 k 张图的像素向量中的第 m 个数”。这里括号里的 k 是样本编号，**不是 k 次幂**。

## 3. 矩阵乘法与逐元素乘法

矩阵乘法的基本规则：

$$\underbrace{A}_{m\times n}\underbrace{B}_{n\times p}
=\underbrace{C}_{m\times p},\qquad C_{ij}=\sum_{r=1}^n A_{ir}B_{rj}.$$

**里面的维度 n 对齐并求和，外面的维度 m、p 留下来。**

例如一行输入 x=[2,3]，权重：

$$W=\begin{bmatrix}1&-1\\4&2\end{bmatrix}.$$

得到 xW=[2×1+3×4, 2×(−1)+3×2]=[14,4]。每一个输出使用 W 的一列。

```python
import numpy as np

x = np.array([[2., 3.]])          # (1, 2)
W = np.array([[1., -1.], [4., 2.]])
print(x @ W)                     # [[14.  4.]]

a = np.array([2., 3.])
b = np.array([4., 5.])
print(a * b)                     # [ 8. 15.]，逐元素乘
print(a @ b)                     # 23.0，向量点积：2*4 + 3*5
```

数学里逐元素乘法常写成 `⊙`。在二维 NumPy 数组上，`A @ B` 与 `A.dot(B)` 都是矩阵乘法；**`A * B` 不会自动帮你做“相乘后求和”**。

## 4. 转置：交换行列，不改变数值

若 A 为 2×3，则 Aᵀ 为 3×2，原来的第一行变成第一列。

```python
A = np.array([[1, 2, 3], [4, 5, 6]])
print(A.T)
# [[1 4]
#  [2 5]
#  [3 6]]
```

> **易错提醒**：一维数组 `(3,)` 没有行轴和列轴之分，`.T` 后仍是 `(3,)`。需要列形状时用 `v[:, None]` 得到 `(3, 1)`，需要行形状时用 `v[None, :]` 得到 `(1, 3)`。

梯度公式中的转置不是装饰。例如 `X.T @ G` 把同一参数在所有样本上的贡献加起来。形状能帮你检查，真正的理由来自链式法则，见[第四章](04-neural-networks-backprop.md)。

## 5. `axis` 与 `keepdims`：到底对谁求和？

取数组：

```python
A = np.array([[1, 2, 3],
              [4, 5, 6]])           # (2, 3)
```

| 代码 | 结果 | 形状 | 含义 |
|---|---|---|---|
| `A.sum(axis=0)` | `[5, 7, 9]` | `(3,)` | 消去行轴，跨行相加 |
| `A.sum(axis=1)` | `[6, 15]` | `(2,)` | 消去列轴，每行内部相加 |
| `A.sum(axis=1, keepdims=True)` | `[[6], [15]]` | `(2, 1)` | 每行求和，但保留长度为 1 的列轴 |

**`axis` 指被聚合的轴；`keepdims=True` 把这个轴留成长度 1。** NumPy 参数名是 `keepdims`，末尾有 s。

计算每张图各类别概率时，每张图放一行，应在类别轴 `axis=1` 上归一化。不同图片之间不应该共同争夺一份总概率。

## 6. 广播：一列加一行，得到整张表

想计算 2 个测试样本与 3 个训练样本之间的距离，需要一个 2×3 的表。

![广播：每行的量与每列的量怎样组合](../assets/beginner/broadcast-grid.png)

图里每个格子是“左侧对应行的值 + 上方对应列的值”。例如第二行第三列为 25+100=125。广播让我们表达这类重复计算，不必自己写双重循环。

```python
test_sq = np.array([[5.], [25.]])  # (2, 1)
train_sq = np.array([10., 50., 100.])  # (3,)
print(test_sq + train_sq)
# [[ 15.  55. 105.]
#  [ 35.  75. 125.]]
```

广播从**最右边的轴**对齐。两个对应轴的大小要相同，或其中一个为 1；缺少的前导轴可按 1 理解。这里 `(3,)` 按 `(1,3)` 与 `(2,1)` 配合。

**为什么距离计算里的 `train_sq` 常不用 `keepdims`？** 因为想让它横向对应训练样本。对训练数据按 `axis=1` 求和，默认得到 `(num_train,)`，广播时正好相当于一行。若保留维度得到 `(num_train,1)`，方向就不对了；可以转置成 `(1,num_train)` 再用。

两种正确写法：

```python
train_sq = (X_train ** 2).sum(axis=1)                     # (M,)
# 或
train_sq = (X_train ** 2).sum(axis=1, keepdims=True).T     # (1, M)
```

这不是“训练数据不允许 keepdims”，而是**最终形状必须能表达每行对应测试、每列对应训练的关系**。

### 接到无循环 L2 距离

对一个测试向量 x 与训练向量 z：

$$\|x-z\|_2^2=\sum_d x_d^2+\sum_d z_d^2-2\sum_d x_dz_d.$$

推广到所有样本：

```python
# X: (N, D)，X_train: (M, D)
# 原始 uint8 图像须先转浮点，避免平方时整数溢出
X = X.astype(np.float64, copy=False)
X_train = X_train.astype(np.float64, copy=False)
test_sq = (X ** 2).sum(axis=1, keepdims=True)       # (N, 1)
train_sq = (X_train ** 2).sum(axis=1)               # (M,)
cross = X @ X_train.T                             # (N, M)
sq_dists = test_sq + train_sq - 2 * cross          # (N, M)
dists = np.sqrt(np.maximum(sq_dists, 0.0))
```

最后的 `maximum` 处理浮点舍入产生的微小负数，不能拿来掩盖错误公式。大数相减仍可能损失精度，这段是课程作业常用展开式，不保证所有极端尺度下都精确。

## 7. `exp`、`log`、概率与期望

`exp(s)=e^s`，`log` 在本笔记默认是自然对数。它们互为反函数：log(e^s)=s。

Softmax 先对各分数取指数，再除以指数总和。交叉熵取正确类别概率的负对数：p=0.5 时 −log(p)≈0.693；p=0.9 时约为 0.105。**正确类别得到更大概率，损失就更小。**

`p(y|x)` 读为“已知 x 时，y 的条件概率”。它一般不等于 `p(x|y)`。`x∼p` 表示“按照分布 p 抽样”。

$$\mathbb E[f(x)]=\sum_x p(x)f(x)$$

上式是离散情况下的期望：按出现概率加权平均。比如值 0、10 的概率分别为 0.8、0.2，期望为 2，但一次采样得到的是 0 或 10，未必是 2。连续分布相应使用积分。

## 8. 导数、偏导与梯度

**导数描述“在当前附近，输入改变一点，输出大约改变多少”。** 若 L(w)=w²，在 w=3 处导数为 6；w 增加很小的 δ 时，损失约增加 6δ。这是局部近似，不是任意大变化都精确成立。

多个变量时，偏导数先固定其他变量。例如 L(w₁,w₂)=w₁²+3w₂，两个偏导为 2w₁ 和 3；把它们放在一起就是梯度。

$$\nabla L=(2w_1,3).$$

若参数 W 是矩阵，它的每一个元素都有对应偏导，所以 **`grad_W.shape == W.shape`**。

链式法则可以用两段局部变化理解。若 u=2w、L=u²，则 w 改一点先使 u 改两倍，u 的变化再影响 L：

$$\frac{dL}{dw}=\frac{dL}{du}\frac{du}{dw}=(2u)\times2.$$

在 w=3、u=6 时，导数为 24，与直接把 L 写成 4w² 后求导一致。神经网络把这条法则应用到很多节点，形成反向传播。

## 9. 常用字母只记角色，不要跨章硬套

| 记号 | 常见读法 | 本课程常见角色 |
|---|---|---|
| θ | theta，西塔 | 参数总称 |
| η | eta，伊塔 | 学习率 |
| λ | lambda，拉姆达 | 正则化或损失项权重 |
| μ | mu，缪 | 均值 |
| σ | sigma，西格玛 | 标准差，或 Sigmoid 函数；看定义 |
| ε | epsilon，艾普西隆 | 小稳定常数，或随机噪声；看定义 |
| τ | tau，陶 | 温度 |
| ∂L/∂W | L 对 W 的偏导 | 参数每个元素的梯度 |

符号会复用，**每次先看定义和形状**。例如 Transformer 的 H 可能是头数，CNN 中 H 常是图像高度。
