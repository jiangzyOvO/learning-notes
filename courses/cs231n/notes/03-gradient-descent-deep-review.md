# 第三讲专题：梯度怎样指导参数更新

从标量导数出发，推导 Softmax 梯度并完成一次线性分类器更新。前置：[Softmax 与交叉熵](02-softmax-numerical-stability.md)。

## 1 先用一个参数理解导数

教学损失 J(w)=(w-3)²，仅用于看清更新机制，不是图片分类交叉熵。

$$
J(w)=(w-3)^2,\qquad J'(w)=2(w-3)
$$

w=0 时损失 9、导数 -6；w=5 时损失 4、导数 4。导数是当前附近参数变化与损失变化的比率，不是损失本身。小变化满足 ΔJ≈J'(w)Δw，因此负导数处增加参数可降低损失，正导数处减少参数可降低损失。

用数据观察，w=0.001 时损失 8.994001，比 w=0 的 9 小。除以参数变化 0.001 得到变化率 -5.999，接近解析导数 -6。

导数为零不能在任意问题上保证全局最小值，可能是最大值、鞍点等。本例平方函数在 w=3 确实达到全局最小值。

## 2 为什么更新要减去梯度

$$
w_{t+1}=w_t-\eta J'(w_t)
$$

η 为正学习率，控制沿负梯度走多远。t 表示更新次数；它不是乘法，也不是类别索引。

```text
w=0，导数=-6，学习率=0.1
新 w = 0 - 0.1×(-6) = 0.6
新损失 = (0.6-3)² = 5.76
```

| 更新次数 | w | 损失 |
|---|---|---|
| 0 | 0 | 9 |
| 1 | 0.6 | 5.76 |
| 2 | 1.08 | 3.6864 |
| 3 | 1.464 | 2.359296 |

不是“永远减小参数”，而是减去导数乘学习率；导数为负时参数反而增大。目标是降低损失，不是让参数一律变小。

## 3 学习率太大不保证下降

仍在 w=0，梯度为 -6：

| 学习率 | 一次更新后的 w | 新损失 |
|---|---|---|
| 0.1 | 0.6 | 5.76 |
| 0.5 | 3 | 0 |
| 1.0 | 6 | 9 |
| 1.1 | 6.6 | 12.96 |

η=1 时后续在 0、6 之间往复；η>1 会逐步偏离。本例误差满足 w_next-3=(1-2η)(w-3)，一般初始值下收敛需要 0<η<1，η=0.5 一步到最优。此范围来自这个特定平方函数，不能搬到所有模型。

## 4 多个参数时每个元素都有偏导数

梯度是所有参数偏导数的集合。对 W、b 求损失梯度，得到与各自形状相同的 grad_W、grad_b：

```python
W = W - learning_rate * grad_W
b = b - learning_rate * grad_b
```

所有梯度基于更新前同一组参数计算，之后一起更新。梯度方向给出局部变化信息，大步更新不保证下降；复杂非凸目标也不保证到达全局最优。

## 5 接回 Softmax：分数梯度为什么是 p 减目标

单样本、无正则化的交叉熵可以写成：

$$
L=-s_y+\log\left(\sum_j e^{s_j}\right)
$$

对类别 c 的分数求导，第一项在 c=y 时为 -1，否则为 0；第二项为 e^(s_c)/sum(exp(s_j))，就是 p_c。因此：

$$
\frac{\partial L}{\partial s_c}=p_c-\mathbf{1}[c=y]
$$

指示函数 1[c=y] 表示条件成立取 1，否则取 0。也可理解成预测概率向量减去 one-hot 目标向量。

沿用输入 x=[2,1]、分数 [2,0,0]，这次给定真实标签 B=1：

```text
预测概率       = [0.786986, 0.106507, 0.106507]
one-hot 目标    = [0,        1,        0       ]
分数梯度       = [0.786986,-0.893493, 0.106507]
```

若直接优化这些分数，负梯度会降低错误类别分数、提高正确类别分数。实际模型优化的是共享的 W、b；它们的更新还会影响其他输入，不能推广为所有样本都必然改善。

## 6 从分数梯度到权重梯度

类别分数 s_c=sum(W_cj*x_j)+b_c。对某个权重求导得到 x_j，对偏置求导得到 1。链式法则把两段影响相乘：

$$
\frac{\partial L}{\partial W_{cj}}=(p_c-\mathbf{1}[c=y])x_j,
\qquad
\frac{\partial L}{\partial b_c}=p_c-\mathbf{1}[c=y]
$$

纯文本：权重梯度 = 对应类别的分数梯度 × 对应输入特征。

```text
grad_W = [[ 1.573972,  0.786986],
          [-1.786986, -0.893493],
          [ 0.213014,  0.106507]]
grad_b = [0.786986, -0.893493, 0.106507]
```

输入为零的位置，该样本的数据损失权重梯度为零；偏置仍可有梯度。不能推广为这个权重在其他样本或含正则化时都无梯度。

## 7 一次真实参数更新

使用前篇同一组 W、b，学习率 0.1，更新后分数约为 [1.527808,0.536096,-0.063904]。更新前损失约 2.239545，更新后约 1.445661；B 的概率从 0.106507 提高到 0.235590。最高分仍属于 A，预测仍错误。因此损失改善不要求准确率每一步都改变。

核心代码（p 已由稳定 Softmax 得到）：

```python
grad_scores = p.copy()
grad_scores[y] -= 1
grad_W = grad_scores[:, None] * x[None, :]
grad_b = grad_scores.copy()
W = W - 0.1 * grad_W
b = b - 0.1 * grad_b
```

grad_scores[:,None] 为 `(C,1)`，x[None,:] 为 `(1,D)`，广播乘积为 `(C,D)`。它是单样本的外积形式，不是一般情况下用逐元素乘法替代矩阵乘法。

完整脚本：[lecture03_gradient.py](../experiments/deep_review/lecture03_gradient.py)。通过中心差分逐参数核对 W、b 的解析梯度；检查这个指定例子更新后损失降低。没有验证或测试成绩，也不能据此声称训练已经完成。
