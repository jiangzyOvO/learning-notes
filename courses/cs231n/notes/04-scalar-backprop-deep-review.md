# 第四讲专题：计算图与标量反向传播

反向传播计算梯度，优化器利用梯度更新参数。先从标量计算图理解局部导数、链式法则和分支累加，再看[矩阵反传](04-matrix-backprop-deep-review.md)。

## 1 前向数值与反向梯度是不同的量

计算图记录每个量怎样由其他量算出。前向顺着依赖计算数值，反向倒着依赖计算最终标量对各量的导数。反向不是把函数求逆，也不是还原输入。

对 f=(x+y)*z，定义 q=x+y，取 x=1、y=2、z=4：q=3、f=12。

```text
x=1 ─┐
     加法 → q=3 ─┐
y=2 ─┘          乘法 → f=12
z=4 ────────────┘
```

这里先对 f 求梯度，f 不一定是损失；在训练图中最终输出通常为标量损失。

## 2 链式法则为什么是相乘

小变化中，x 改变影响 q，q 改变再影响 f，所以变化率相乘：

$$
\frac{\partial f}{\partial x}
=\frac{\partial f}{\partial q}\frac{\partial q}{\partial x}
$$

乘法节点 f=q*z：∂f/∂q=z=4、∂f/∂z=q=3。加法节点 q=x+y：∂q/∂x=∂q/∂y=1。因此 ∂f/∂x=4、∂f/∂y=4、∂f/∂z=3。

f 对自己的导数为 1，因此从最终节点梯度 1 开始。对于训练损失 L，∂L/∂L=1，并非“损失值必须为 1”。

纯文本：传向某个输入的梯度 = 已知最终目标对节点输出的梯度 × 节点输出对这个输入的局部导数。

## 3 常见节点规则

设上游梯度 g 为最终损失对该节点输出的导数：

| 节点 | 局部导数 | 传向输入的梯度 |
|---|---|---|
| q=a+b | 对 a、b 都为 1 | 各得到 g |
| q=a*b | 对 a 为 b，对 b 为 a | 分别为 g*b、g*a |
| q=a² | 2a | g*2a |
| q=max(0,a) | 正区间 1、负区间 0 | g*(a>0) |

乘法节点不是无条件把同一个梯度复制给两端；加法节点才在这个简单标量形式下各传 g。ReLU 在零点不可导，本系列实现约定导数为零。

## 4 同一变量走多条路径，要累加贡献

f=x*x+x，取 x=3。乘法的两个输入位置都是 x，各贡献 3；直接加法路径贡献 1，总梯度为 3+3+1=7。

$$
\frac{df}{dx}=2x+1
$$

因此一般反传在共享节点累积时使用 +=。不要只保留最后一条路径。偏置广播、批量共享权重、卷积共享权重和 RNN 时间共享，都需要汇总多处使用产生的贡献。

## 5 一个完整的标量网络

沿用第四讲主笔记算例，方便与原图和代码对应：

$$
a=wx+b,\quad h=\max(0,a),\quad \hat y=vh+c,\quad
L=\frac12(\hat y-y)^2
$$

| 量 | 本例数值 | 含义 |
|---|---|---|
| x | 2 | 固定输入 |
| y | 1 | 固定回归目标 |
| w、b | 1、-1 | 第一层参数 |
| v、c | 2、0 | 第二层参数 |
| a、h | 计算得到 | 激活前与激活后 |
| y_hat | 计算得到 | 回归预测 |

这里 y=1 是一个回归目标值，不是 Softmax 分类的类别编号。平方误差和 ReLU 用于手算，不与上篇交叉熵混用。

前向：a=1、h=1、y_hat=2、残差=1、L=0.5。

## 6 反向逐层追踪

先从平方损失：∂L/∂y_hat=y_hat-y=1。再按输出层、ReLU、第一层倒序：

```text
输出层 y_hat=v*h+c：
grad_v = 1*h = 1
grad_c = 1
grad_h = 1*v = 2

ReLU h=max(0,a)：
a=1>0，局部导数为 1
grad_a = 2*1 = 2

第一层 a=w*x+b：
grad_w = 2*x = 4
grad_b = 2
grad_x = 2*w = 2
```

grad_a=2 表示最终损失对 a 的导数；a 的数值本身为 1。名称相近，但数值与导数必须分开记录。

grad_x 也能计算，因为输入是图的一部分；普通监督训练中仍把 x 当数据，只更新 w、b、v、c。对输入求梯度的其他用途后续再讨论。

核心代码：

```python
# 前向保存必要的旧值
a = w * x + b
h = max(0.0, a)
y_hat = v * h + c
loss = 0.5 * (y_hat - y) ** 2

# 反向：先算全套梯度，不在中途更新参数
grad_y_hat = y_hat - y
grad_v = grad_y_hat * h
grad_c = grad_y_hat
grad_h = grad_y_hat * v
grad_a = grad_h * (1.0 if a > 0 else 0.0)
grad_w = grad_a * x
grad_b = grad_a
grad_x = grad_a * w
```

不要先更新 v，再用新 v 计算 grad_h；那不再对应同一次前向的梯度。

## 7 更新后重新前向，不能沿用旧激活

学习率 0.01，所有参数同时按旧梯度更新：w=0.96、b=-1.02、v=1.99、c=-0.01。重新前向 a=0.9、h=0.9、y_hat=1.781、L=0.3049805，比旧损失 0.5 小。

若学习率改为 0.1：w=0.6、b=-1.2、v=1.9、c=-0.1，得到 a=0、h=0、y_hat=-0.1、L=0.605。大步走到激活边界、越过合适位置；梯度正确仍不保证这个有限步长下降。

## 8 ReLU 截断的是这一条路径

用同一参数，但输入 x=0：a=-1、h=0、y_hat=0、L=0.5。反向 grad_h=-2，但 ReLU 导数为零，grad_a=0；grad_w、grad_b、grad_v 均为零，grad_c=-1。

这里“梯度被挡住”是对经过该 ReLU 的当前样本路径而言。不是整张计算图所有梯度都为零，也不能断定它在所有样本中永远无法学习。另有正则化梯度时也应加入相应参数。
