# 第五讲专题：卷积反传、池化、感受野与完整 CNN

在[卷积前向](05-convolution-forward-deep-review.md)的基础上，推导共享权重的梯度，并计算池化、GAP、感受野和完整 CNN 的形状。

## 1 卷积反传还是乘局部导数再相加

前向每个位置 out=sum(patch*kernel)+bias。该位置上游梯度为 g：核梯度贡献 g*patch；输入窗口梯度贡献 g*kernel；偏置梯度贡献 g。

同一个核用于所有样本、空间位置，所以核梯度累加。一个输入像素被多个重叠窗口读取、还可能影响多个输出通道，所以输入梯度也累加。反向用同一次前向的核和窗口，不在中途更新。

```python
d_kernel += g * patch
d_input_patch += g * kernel
d_bias += g
```

这三行是局部贡献，完整函数需对样本、输出通道和输出位置循环。卷积层不额外无条件平均梯度；平均损失的系数应已包含在传来的上游梯度里。

## 2 沿用 3×3 输入与 2×2 核

```text
输入：       核：        输出：
1 2 3        1  0        -4 -4
4 5 6        0 -1        -4 -4
7 8 9
```

指定每个输出的上游梯度为 1，可用教学标量目标 L=sum(out) 实现。它不是分类交叉熵，也不是从输出值 -4 自动推出梯度。

核左上权重使用的输入依次为 1、2、4、5，因此梯度为 12。其他权重同理：

```text
d_kernel = [[12,16], [24,28]]
d_bias = 4
d_input = [[1,1,0], [1,0,-1], [0,-1,-1]]
```

中心输入 5 在四个窗口中分别乘核权重 -1、0、0、1，梯度贡献相加为 0。不是没有路径，而是贡献抵消。

## 3 带填充和步长的反向代码

先在补零后的数组上累加，最后裁出原输入区域。以下为核心片段，X 与 weights 为浮点 NCHW，形状已与前向核对；无 groups、无 dilation：

```python
patch = padded[n, :, top:top+K_h, left:left+K_w]
g = upstream[n, c, row, col]
d_weights[c] += g * patch
d_padded[n, :, top:top+K_h, left:left+K_w] += g * weights[c]
```

top=row*stride、left=col*stride，与前向起点一致。偏置可一次求和 `upstream.sum(axis=(0,2,3))`。补零是固定输入，不是可学习参数；裁剪使用 `padding:padding+H`，padding=0 时也正确，避免 `0:-0` 变空切片。

## 4 池化分别处理每个通道

最大池化在窗口取最大值，平均池化取均值；普通池化不混合通道，也没有可学习核参数。它仍需要反传输入梯度，以继续训练前面的卷积。

窗口 [[1,3],[2,0]]：max=3、mean=1.5。上游梯度 8 时，唯一最大值位置收到 8；平均池化四个位置各收到 2。

最大值并列时不可按唯一可导规则处理，本教学实现选择展开顺序的第一个最大位置。不要在并列点要求中心差分与该约定唯一一致。

重叠窗口需要 +=。输入 [[1,2,3],[4,9,6],[7,8,0]]，2×2、步长 1 的四个窗口都选中心 9，每个上游为 1，中心输入梯度总和为 4。前向应缓存被选位置，反向按同一选择分配。

## 5 全局平均池化 GAP

GAP 对每个通道的全部空间位置平均，输入 `(N,C,H,W)` 变为 `(N,C)`：

```python
features = activations.mean(axis=(2, 3))
```

反向每个位置收到该通道上游梯度除以 H*W。8×8 空间时，每个位置收到 1/64 的对应通道梯度。它不平均通道或批次，也没有可学习参数；会汇总空间信息，不能替代定位任务需要的全部空间表示。

## 6 感受野和输出中心间距

感受野 r 是一个输出单元理论上可能依赖的原输入范围，jump j 是相邻输出中心在原输入中的间距。初始 r=j=1。层的有效核大小 k、步长 s：

$$
r_{\mathrm{new}}=r_{\mathrm{old}}+(k-1)j_{\mathrm{old}},\qquad
j_{\mathrm{new}}=j_{\mathrm{old}}s
$$

先用旧 j 算新 r。膨胀核用有效核大小，不直接用参数核宽。

| 层 | k、s | 感受野 r | 间距 j |
|---|---|---|---|
| 输入 | — | 1 | 1 |
| 3×3 卷积 | 3、1 | 3 | 1 |
| 2×2 池化 | 2、2 | 4 | 2 |
| 3×3 卷积 | 3、1 | 8 | 2 |
| 2×2 池化 | 2、2 | 10 | 4 |

最终某一个空间单元的理论感受野为 10×10，不是整张图；GAP 汇总全部空间单元，分类分数能综合全图。边界的理论范围可能覆盖固定填充；实际图像像素影响取决于权重、激活和池化选择，不代表范围内像素贡献都相同。

## 7 完整分类形状链与参数

卷积核均 3×3、stride=1、padding=1；池化均 2×2、stride=2；单样本形状：

| 层 | 输出形状 | 可学习参数 |
|---|---|---|
| 输入 | 3×32×32 | 0 |
| Conv1，16 输出通道 | 16×32×32 | 16*(3*3*3+1)=448 |
| ReLU | 16×32×32 | 0 |
| MaxPool | 16×16×16 | 0 |
| Conv2，32 输出通道 | 32×16×16 | 32*(16*3*3+1)=4640 |
| ReLU | 32×16×16 | 0 |
| MaxPool | 32×8×8 | 0 |
| GAP | 32 | 0 |
| Linear 到十类 | 10 | 32*10+10=330 |

总参数 5418，未包含其他层。若用展平替代 GAP，特征为 32*8*8=2048，十类线性头参数为 2048*10+10=20490；两种分类头不同，不是展平把数值丢掉。

十个输出是类别分数，接稳定交叉熵；预测 argmax。网络中间的 16、32 是特征通道，不是类别数。

## 8 反向怎样接成整张图

```text
交叉熵的分数梯度
→ Linear：权重、偏置梯度与 32 维特征梯度
→ GAP：按 8×8 位置分配
→ MaxPool2：按前向选中位置分配
→ ReLU2：乘正区间掩码
→ Conv2：共享权重累加与输入梯度
→ MaxPool1 → ReLU1 → Conv1
→ 全部梯度算完后更新参数
```

无可学习参数的层仍是反传路径的一部分。L2 等正则化按目标直接加入被惩罚参数，不混入激活梯度。整张图的完整训练还需要训练数据、损失、优化器、批量管理与验证。

## 9 平移等变与不变要区分

步长 1 的共享卷积在适当平移及边界条件下，输入移动会导致特征图对应移动，称等变；不是特征图完全不变。有限边界、填充、步长采样和池化会限制严格等变。局部池化可能提供一定位置鲁棒性，不能保证对任意平移都不变。
