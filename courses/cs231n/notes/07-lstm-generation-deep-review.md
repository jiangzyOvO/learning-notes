# 第七讲专题：LSTM 的门、反向传播与生成流程

在[RNN 与 BPTT](07-rnn-bptt-deep-review.md)的基础上，推导 LSTM 的门、状态与梯度，再连接训练和生成。采用每行一个样本的约定。

## 1. 从普通 RNN 到两种状态

普通 RNN 在每一步用 tanh 更新隐藏状态，长距离梯度经历多次矩阵与非线性导数连乘。LSTM 增加独立的 cell state（记忆状态）c，用可学习的门控制保留和写入，改善长距离传播路径，但不保证无限记忆或任意长度梯度稳定。

**h 是给输出层及下一步门计算使用的隐藏状态；c 是另行维护的记忆状态。两者不是同一个数组。** 状态随序列变化，权重跨时间共享。新独立序列通常初始化两种状态为零；同一序列分片时可按任务传递状态，截断梯度与保留数值要分别处理。

## 2. 先算记忆，再看门怎样产生

逐元素更新为：

```text
c = f * c_prev + i * g
h = o * tanh(c)
```

| 符号 | 名称 | 数值与作用 |
|---|---|---|
| f | 遗忘门 | sigmoid 输出，0 到 1，控制旧记忆保留比例 |
| i | 输入门 | sigmoid 输出，控制候选内容写入比例 |
| g | 候选内容 | tanh 输出，−1 到 1，是准备写入的数值，不是门 |
| o | 输出门 | sigmoid 输出，控制当前记忆暴露给 h 的比例 |

门不是三个 Softmax 类别，**不要求 i+f+o=1**。不同记忆分量各有自己的门值，门由参数、当前输入与之前的 h 共同计算，并非人工指定规则。

教学手算假设 c_prev=2、f=0.9、i=0.2、g=−0.5、o=0.8：

```text
保留旧内容：0.9 * 2 = 1.8
写入新内容：0.2 * (-0.5) = -0.1
c = 1.8 - 0.1 = 1.7
h = 0.8 * tanh(1.7) ≈ 0.748327
```

c 可以超过 1；h 经过 tanh 与输出门，在标准单元里受限于 −1 与 1。减小 o 可以减少当前输出，**并不直接清空 c**。为演示先指定门值；真实门值要从下面的仿射运算计算。

## 3. 四组计算合成一次矩阵乘法

令批大小 N、输入维度 D、隐藏维度 K。把 x 与 h_prev 沿特征轴拼接成 z：

| 变量 | 形状 |
|---|---|
| x | (N,D) |
| h_prev、c_prev | (N,K) |
| z=[x,h_prev] | (N,D+K) |
| W | (D+K,4K) |
| b | (4K,) |
| a=z@W+b | (N,4K) |

本实现约定块顺序 i、f、o、g。不同实现可能顺序不同，移植权重必须核对。

```python
z = np.concatenate([x, h_prev], axis=1)
ai, af, ao, ag = np.split(z @ W + b, 4, axis=1)
i, f, o = sigmoid(ai), sigmoid(af), sigmoid(ao)
g = np.tanh(ag)
c = f * c_prev + i * g
h = o * np.tanh(c)
```

这里 @ 是矩阵乘法，* 是逐元素乘法。四块表示四组不同的权重，不是共用同一组权重输出四次。若 D=3、K=4，则 W 是 7×16，共 112 个权重，再加 16 个偏置，合计 128 参数，与序列长度无关。不计 embedding、输出层、多层结构。

## 4. 记忆路径为什么更容易传递梯度？

在把门值作为当前节点固定输入时，c 对 c_prev 的直接逐元素导数是 f。跨多步的这条直接路径出现遗忘门乘积：

```text
f 每步为 0.99：0.99**20 ≈ 0.818
f 每步为 0.5： 0.5**20  ≈ 0.000000954
```

因此接近 1 的 f 有助于保留直接路径。但完整循环计算图还包含 c→h→未来门等路径，完整导数不只等于遗忘门乘积。LSTM 仍可能出现梯度问题；梯度裁剪、学习率、初始化和序列处理仍需考虑。

## 5. 把反向传播拆成两条状态路径

以下 dh 是损失对当前 h 的总梯度（当前输出与未来 h 路径相加），dc_future 是未来经 c 路径传回的梯度。令 v=tanh(c)：

```python
do = dh * v
dc_total = dc_future + dh * o * (1 - v**2)

df = dc_total * c_prev
di = dc_total * g
dg = dc_total * i
dc_prev = dc_total * f

dai = di * i * (1 - i)
daf = df * f * (1 - f)
dao = do * o * (1 - o)
dag = dg * (1 - g**2)
```

**dc_total 必须相加两路贡献**：c 一路影响当前 h，一路直接影响未来 c。只计算其中一路会漏梯度。若本步损失也直接依赖 c，还要加上对应局部梯度。

将四块梯度拼回原顺序：

```python
da = np.concatenate([dai, daf, dao, dag], axis=1)
dW += z.T @ da
db += da.sum(axis=0)
dz = da @ W.T
dx = dz[:, :D]
dh_prev = dz[:, D:]
```

沿时间倒序执行，把 dh_prev 和 dc_prev 分别传给前一步。共享 W、b 的贡献累加；完成反传后更新参数。若损失取有效 token 平均，平均系数应已包含在输出梯度中，不要再在每一层重复除以 N 或 T。

## 6. 训练语言模型：输入和目标错开一位

例子使用人为指定的词级 token，并加入起止标记：

```text
原序列：<START> 我 爱 猫 <END>
输入：  <START> 我 爱 猫
目标：  我      爱 猫 <END>
```

每步真实输入 token→embedding 查表→LSTM 更新→输出分数→交叉熵。Embedding 表 E 的形状是 (V,D)，token_ids 为 (N,) 时 E[token_ids] 为 (N,D)。token 编号是索引，不是有数值距离意义的特征。

输出层 W_y 为 (K,V)，scores=h@W_y+b_y 为 (N,V)。稳定交叉熵先减去每行最大分数，再算 log-sum-exp。最后沿时间和批次汇总损失，反向经过输出层、LSTM 与 embedding。embedding 同一 token 多次出现时，查表行梯度也要累加。

**Teacher forcing** 是训练时送入真实的前一个 token，而不是模型刚预测的 token。标签只在损失里用于监督下一项，不应作为预测该项前的未来输入。短序列补齐后应屏蔽 padding 对损失的贡献；如要求正确最终状态，还需要妥善处理补齐时间步的状态更新，单独屏蔽损失并不自动解决状态问题。

## 7. 生成时没有真实的下一个 token

```text
输入 START → 预测“我”
输入“我”   → 预测“爱”
输入“爱”   → 预测“猫”
输入“猫”   → 预测 END，停止
```

这是说明流程的假想正确结果，不是实验成绩。每次使用自己选出的 token 作为下一次输入，同时保留 h、c；不应每一步重置状态。设置 END 停止与最大步数，以限定生成长度。训练与生成的输入来源不同，生成错误可能累积。

可用 argmax 做贪心解码，也可根据概率随机采样。温度 tau 必须为正：

```python
shifted = scores / tau
shifted -= shifted.max(axis=-1, keepdims=True)
p = np.exp(shifted)
p /= p.sum(axis=-1, keepdims=True)
```

指定 scores=[2,1,0] 时，tau=0.5 的概率约 [0.8668,0.1173,0.0159]，tau=2 时约 [0.5065,0.3072,0.1863]。较低温度更集中，较高温度更平坦，不保证内容正确；正温度不改变 argmax 的位置。贪心不保证整句联合概率最大。

## 8. 图像描述怎样连接 CNN 与 LSTM？

CNN 提取图片特征 v，作为生成条件。一个可选教学设计是 h0=v@P+b，c0=0，再从 START 开始生成；P 将图片特征维度映射到 K。也可以把图片特征作为额外输入，具体接法需看模型定义。若训练此设计，h0 的梯度还能传回 P，骨干是否更新取决于冻结设置。

训练时图片条件加真实前词，监督下一词；生成时图片条件加已生成词。固定向量需要压缩图片信息；流畅文字不自动代表忠实于图片。

GRU 是原主笔记明确标注的补充：门控更新、通常无独立 c；不同约定的更新门语义可能相反，不能只靠名字套公式。详见[主笔记第八节](07-recurrent-networks.md#8-补充gru-与-lstm-的联系)。
