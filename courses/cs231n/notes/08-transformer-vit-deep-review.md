# 第八讲专题：多头、位置与完整 Transformer / ViT

在[单头注意力](08-attention-qkv-deep-review.md)的基础上，加入多头、位置表示、归一化与残差，连接完整 Transformer block 和 ViT 前向。示例 MLP 使用 ReLU。

## 1. 多头让同一输入经过多组不同投影

设 X=(B,T,D)，头数 H，演示中每头维度 d=D/H。每头的 Wq/Wk/Wv 各有不同参数，输出为 (B,T,d)。拼接 H 个输出得到 (B,T,D)，再经 Wo=(D,D) 混合各头特征。不保证特定头必然学到颜色、语法等可命名关系。

以 B=2、T=3、D=4、H=2 为例：

```text
投影 Q/K/V：       (2,3,4)
拆头并转置：       (2,2,3,2) = 批、头、位置、每头特征
分数/权重：        (2,2,3,3) = 批、头、查询位置、key位置
各头输出：         (2,2,3,2)
转置后拼接：       (2,3,4)
输出投影后：       (2,3,4)
```

缩放因子是 sqrt(每头的 d)，不是 sqrt(整个 D)。Softmax 在最后的 key 轴，不能沿头或批次归一化。投影成 D 维再按列切开，等价于每头分别使用对应的权重列；不是直接把原输入切开后只让某个头看到局部输入特征。

## 2. 位置为什么需要额外表示？

不加位置相关信息、没有掩码等位置约束的自注意力：如果 X 重排，QKV 的行同步重排，分数行列同步重排，输出行也同步重排。这叫置换等变，不是输出完全不变。

它可以处理内容之间的关系，但仅靠这个算子不能确定绝对前后位置。例如“狗追人”与“人追狗”需要顺序线索。可加学习的位置向量 P：

```python
X_with_position = X + P
```

移动内容而保持各槽位的位置向量固定，内容与位置的组合会改变。若把内容和位置向量整体一起移动，则整体 token 行仍同步重排。因果掩码也提供位置结构，不能对带固定因果掩码的算子直接套用完全无位置约束的性质。

固定正弦位置、学习位置、相对位置机制是不同办法；二维图片位置表示提供空间线索。位置向量不是标签或损失。

## 3. Pre-Norm Transformer block 的完整流程

```python
U = X + MHA(LN(X))
Y = U + MLP(LN(U))
```

| 组件 | 作用 | 输出形状 |
|---|---|---|
| LN | 对每个 token 的特征轴归一化 | (B,T,D) |
| MHA | 让不同位置交换信息 | (B,T,D) |
| 第一次残差 | 原表示加注意力更新 | (B,T,D) |
| LN | 再次归一化 | (B,T,D) |
| MLP | 每个位置内部做非线性特征变换 | (B,T,D) |
| 第二次残差 | 原中间表示加 MLP 更新 | (B,T,D) |

**注意力跨 token 混合；MLP 通常不直接混合 token，而在每个位置使用同一套参数。** LN 沿最后的 D 维，不是跨 batch 或跨 token 求统计量。

本演示 MLP：

```python
hidden = np.maximum(normalized @ W1 + b1, 0)
update = hidden @ W2 + b2
```

W1=(D,4D)，W2=(4D,D)。中间变宽后再投影回 D，以便做残差相加。采用 ReLU 为了衔接已学内容，常见模型也使用 GELU 或门控变体，不将此演示视为所有模型的定义。Post-Norm 将归一化放在残差相加之后，顺序不同。

Pre-Norm 的直接残差路径帮助信息与梯度传递，但不能把整体导数说成只有恒等项。重复多个 block，token 形状通常保持，表示逐层更新。

## 4. 参数与训练链怎样连接？

示例 D=4、MLP中间宽度16，四组注意力权重和偏置为4D²+4D，两层MLP为2D×16+16+D，两次LN各有gamma/beta共4D，总计244参数。不计位置、embedding和任务头。

语言模型：token embedding+位置→多个带因果掩码的block→词表分数→右移目标交叉熵。训练时可以一次输入所有已知前缀位置，掩码限制每个位置可读范围；生成时下一token依赖已生成token，因此通常逐步生成。训练位置并行与生成逐步进行并不矛盾。

学习过的链式法则仍适用：任务头→MLP及残差→LN→注意力及残差→输入。上一节验证了注意力梯度，第六讲验证了LN，第六讲也解释了残差；本节代码只运行完整block前向，没有执行联合block反传或训练。

## 5. ViT：把图片拆成可处理的 token

输入224×224×3，patch边长16：每边14块，共196块；每块展平为768数字，再投影到D维。加一个分类token CLS后有197个token，再加位置表示：

```text
图片 → 196×768 的patch数组 → 196×D
     → 加CLS得到197×D → 加位置
     → Transformer → 读取CLS输出 → 分类头
```

CLS是可学习的输入向量，训练使它的最终表示可用于分类，不是提前输入的正确标签。也可对patch表示做平均池化再分类。patch线性投影能用核大小与步长均为patch边长的卷积实现，前提是展平与权重排列对应。

教学代码使用2张8×8 RGB图片、4×4 patch、D=4、H=2：patch数组(2,4,48)；加CLS和位置后(2,5,4)；单block及最终LN后读取CLS，三类分数(2,3)。随机权重只演示流程，没有类别准确率意义。

## 6. 成本与现代组件

显式权重表每头是T×T，token数翻倍，该表元素变四倍。主要注意力乘法约O(B T² D)，投影和MLP还约O(B T D²)。具体内存与运行时间受实现影响，不能把理论表大小直接视为实际显存必然完整存储。

保持图片大小，将patch边长从16减为8，patch数从196变784（4倍），对应patch-only注意力表变16倍；小patch保留更细粒度，也增加开销。

课件后部组件的概念入口：RMSNorm用均方根归一化而不减均值；SwiGLU用SiLU分支与另一投影逐元素相乘形成门控MLP；MoE路由到部分专家MLP。MoE总参数量、每token激活参数量与通信成本不同。这些组件未在本节代码实现，详细定义保留在[主笔记](08-attention-transformers.md#11-本版课件还讲了哪些现代组件)。
