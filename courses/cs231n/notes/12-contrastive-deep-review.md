# 第十二讲专题：视图、InfoNCE 与表示坍塌

自监督学习需要从数据构造监督目标。本节推导对比损失、归一化梯度，并分析表示坍塌。

## 1. 没有人工类别，仍要有监督目标

监督分类由人提供类别；自监督从原始数据、变换关系或相关模态中构造目标。不是没有损失或不需要数据。先训练编码器提取表示，再用于分类、检测、检索。预训练目标低不等于下游表现好。

## 2. 两种视图从同一原图生成

原图A裁剪/颜色变换两次生成A1/A2，是正对；另一图B的B1/B2通常当作其他候选。视图不一定是摄像机的两个视角，也可以是增强后的版本。配对标签来自原图身份，不需要人标注“猫”。

增强规定哪些变化应该被忽略。若下游关心颜色，强颜色变换可能破坏有效信息；两次裁剪不共享对象时，正对也可能不符合希望的语义。两张原图都为同类猫，却被当成负样本，是假负样本问题。

## 3. 编码器与投影头

```text
视图x → 编码器f → 特征h → 投影头g → 向量z → 归一化 → 对比损失
```

归一化向量u=z/||z||，点积u_i·u_j等于余弦相似度；未归一化的普通点积不等于余弦。代码排除零长度向量以保证定义与梯度一致。下游通常使用h，未必使用投影空间z，因为投影目标与最终任务可能不同。

## 4. InfoNCE：候选视图中的搭档分类

对每个anchor，候选含一个正样本及负样本，排除anchor自己。候选分数是余弦相似度/正温度tau。Softmax分配候选概率，再取正确搭档负对数，等价于这个候选分类的交叉熵。

指定已温度缩放分数[ln4,ln2,0]，第一个是正样本：指数[4,2,1]，正确概率4/7，损失−ln(4/7)=0.559616。这个手算用于说明交叉熵，不是声称它恰好来自代码归一化向量的实际点积。

若两张原图，每张两视图，按[A1,B1,A2,B2]排，正搭档索引为[2,3,0,1]。每行有三候选：一个正、两个负；不是四项，因为自身排除。

## 5. 实现与形状

```python
unit = raw / np.linalg.norm(raw, axis=1, keepdims=True)
scores = unit @ unit.T / temperature
np.fill_diagonal(scores, -np.inf)
```

raw=(2B,D)，scores=(2B,2B)。沿行做稳定Softmax，每行和为1、对角权重为0。中心减最大值后计算log-sum-exp形式损失，不先把可能下溢为0的概率取log。

本代码对所有anchor损失平均（包含两个方向），不是只计算A1→A2。温度影响权重与梯度尺度；低温更强调高相似度候选，不保证越低越好。

## 6. 把梯度连接到前面的矩阵求导

M=2B，p为候选概率，target矩阵每行在正搭档列为1。对温度缩放后的分数：dS=(p-target)/M。对角线被屏蔽，对应梯度为0。

因为unit同时在点积的左边和右边出现：

```python
dunit = (dS + dS.T) @ unit / temperature
draw = (dunit - unit * (dunit * unit).sum(axis=1, keepdims=True)) / norms
```

归一化反向去掉径向分量，不是简单把dunit除以norms。此后再经过投影头与编码器反传。本代码只验证向量层，不包含图像编码器梯度。

## 7. 坍塌为什么会发生？

只最小化同图视图距离时，所有输入输出相同常量，正对误差也是0；模型却不能区分不同图片。

四个非零相同向量，所有候选相似度相同，每行正搭档概率1/3，InfoNCE=ln3≈1.098612。本代码构造的有结构向量损失约0.422216，较低，说明对比目标不把所有一样的表示当成最好的匹配。

但本对称归一化例子精确坍塌的梯度也为0，所以不能把“损失更高”说成“无条件保证逃离坍塌”。训练效果仍取决于数据、初始化、增强、优化与整体结构。非对比方法需要另外的防退化机制，下一节展开。

## 8. SimCLR 与 MoCo

SimCLR在batch内使用两视图：B原图、2B表示，每anchor有2B−1候选。批次、增强、投影头重要；增大批次也增加显存与相似度表成本。

MoCo用队列保存key表示，key编码器参数由query编码器指数移动平均更新：theta_k=m*theta_k+(1−m)*theta_q。旧表示不必保存全部梯度图，动量更新有助于字典一致性。这里平均网络参数，不是优化器Momentum的梯度速度。

代码是SimCLR风格的向量损失，不实现MoCo队列或多GPU跨卡候选收集。

## 9. 怎样评估表示是否有用？

线性探测冻结编码器、训练线性头；微调更新部分或全部编码器；特征kNN在学习的表示上找邻居。这接回前面迁移学习与第二讲近邻，但下游数据划分必须规范。无人工预训练类别，不代表下游评估也不需要标签。

[lecture12_contrastive.py](../experiments/deep_review/lecture12_contrastive.py)核对搭档索引、排除自身、概率行和、正比例缩放不改变归一化损失、对称向量梯度与坍塌。中心差分最大绝对误差约2.17×10⁻¹¹。没有图像增强管线、编码器训练或下游成绩。
