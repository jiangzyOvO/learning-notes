# 第十三讲专题：概率、似然、自回归与潜变量入口

先区分概率、密度和似然，再用链式法则建立自回归生成流程。VAE 目标见[配套专题](13-vae-elbo-deep-review.md)。

## 1. 从给图片分类到给图片本身建模

判别分类常描述p(y|x)，生成模型可以描述p(x)或条件p(x|c)。条件c可以是文字、类别或其他观测。自监督描述监督来源，生成建模描述目标，两者不是互斥分类；MAE重建目标用于表示学习，不自动等于已定义可从先验采样的图像生成模型。

离散概率对应具体结果，所有互斥完整结果概率和为1。连续密度p(x)不等于精确点的概率，密度可以大于1，区间概率由积分给出。似然是固定观测后，把这些概率/密度作为参数函数看待，不是参数本身的概率。

## 2. 最大似然与负对数似然

独立同分布建模下，样本联合似然是各样本概率乘积。最大化似然等价最大化对数似然，等价最小化负对数似然NLL。

```text
数据越可能 → -log p越小
多个概率相乘 → 取log后相加
```

离散类别交叉熵是NLL的熟悉例子。归一化分布意味着不能把所有互斥结果概率同时提高到1。训练数据NLL下降不自动证明泛化或生成质量。

## 3. 自回归的概率链式法则

```text
p(x1,x2,x3) = p(x1) * p(x2|x1) * p(x3|x1,x2)
```

这是条件概率精确分解，不假设元素相互独立，也不强制只依赖相邻一个元素。模型架构决定如何表达条件分布。

指定某序列路径概率0.8、0.5、0.25，联合为0.1；NLL=−log0.1≈2.302585，等于三个负对数之和。

对二值元素，模型可输出该条件下值1的概率，值0概率为其补数；Softmax可用于多值token。训练基于真实前缀，每步监督真实当前值，并汇总各步NLL。

## 4. 掩码与图像顺序

图像可按确定的像素/通道顺序排列。PixelCNN用掩码卷积限定读取已在前缀中的内容，PixelRNN用循环结构。这里掩码服务概率因果依赖，与MAE随机遮挡后恢复不是同一规则。

实现必须避免当前位置从输入直接读到待预测的像素/通道；右移输入或合适掩码细节取决于架构。训练可以利用已知真实前缀并行计算某些结构的位置，生成则依次采样，不因一次前向能产生很多分数就消除依赖。

## 5. 三位模型与抽样

代码用七个预设条件节点：root、0、1、00、01、10、11，节点值1概率为[.8,.1,.5,.2,.7,.4,.25]。八个序列概率：

| 序列 | 概率 |
|---|---|
| 000 | .144 |
| 001 | .036 |
| 010 | .006 |
| 011 | .014 |
| 100 | .240 |
| 101 | .160 |
| 110 | .300 |
| 111 | .100 |

总和为1。生成先抽第一位，根据它选择第二位条件，再根据前两位选择第三位条件。不是从真实目标读取前缀。20000次抽样频率与指定分布接近，这是采样正确性演示，不是学习成绩。

二步反例：p(x1=1)=.6，p(x2=1|0)=.99，p(x2=1|1)=.6。贪心选11，概率.36；01概率.396，反而更大。贪心逐步最优不等于整段联合最优，也不等于按分布随机采样。

## 6. Autoencoder与生成入口

普通确定性AE：x→编码器→z→解码器→重建，优化重建误差。它只约束训练图编码到的区域，未必指定从哪里抽z，随机输入任意z不保证合理输出。

潜变量生成模型另指定先验p(z)，例如标准正态，然后z→解码器给出p_theta(x|z)。总体p_theta(x)=积分p_theta(x|z)p(z)dz。z是未观测变量，不天然一维对应颜色或姿态，解码器输出的是分布参数，不一定直接是一次随机样本。

简单固定示例：z~N(0,1)，解码均值2z+1，x~N(2z+1,0.5²)。输出均值与从观测分布再次采样不同。此例未训练。

## 7. VAE为什么有编码器？

生成只需先验与解码器；但训练面对真实x，希望知道哪些z能解释它。真实后验p_theta(z|x)通常难计算，编码器提供近似q_phi(z|x)。

| 分布 | 问题 |
|---|---|
| p(z) | 尚未看到x，z怎样抽？ |
| q_phi(z∣x) | 已看到x，哪些z可能解释它？ |
| p_theta(x∣z) | 给定z，x怎样产生？ |

训练路径：x→编码分布→抽z→解码→训练目标。生成路径：从先验抽z→解码，不需要先有新图片。

编码器常输出mu与logvar，并用z=mu+exp(0.5*logvar)*epsilon采样。epsilon是标准正态噪声；logvar是对数方差，不是标准差。下一节推导重参数化、KL和ELBO，不能把本节先验示例当完整VAE。
