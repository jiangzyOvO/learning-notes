# 第十五讲专题：三维表示、点云与可微渲染

从二维像素转到空间坐标，先选择三维表示，再讨论点云学习与可微渲染。

## 1. 一张图片为什么不能唯一决定深度？

简化针孔相机u=f*X/Z、v=f*Y/Z（忽略主点偏移，坐标相对于相机）。f=100时，空间点(1,2,4)与(2,4,8)均投影到(25,50)。后者更远但横纵坐标按相同比例变大。

投影丢失深度信息，遮挡还隐藏部分表面。单视图重建依赖线索和先验，多视图有更多约束但仍需相机关系与可见性。像素、三维坐标、相机坐标不是同一个单位与参考系。

## 2. 四种表示保存的信息不同

| 表示 | 内容 | 适合理解的限制 |
|---|---|---|
| 点云 | N个三维点，可加颜色、法线 | 没有显式连面，通常无序 |
| 网格 | 顶点、边/面连接 | 表面清晰，需维护拓扑与合法性 |
| 体素 | R×R×R网格占据/特征 | 轴分辨率翻倍，元素8倍 |
| 隐式场 | 坐标到占据/距离等值的函数 | 需查询采样或提取表面 |

![表示差异的原创示意](../assets/remaining/15-representations.png)

32³=32768，64³=262144。体素方便网格运算，但保存表面附近信息也可能占用大量空白区域。稀疏表示节省资源的同时增加算子/索引复杂度。

## 3. PointNet为什么不怕点顺序被打乱？

每点共享网络phi，随后对点轴做对称聚合：global=max_i(phi(point_i))，再分类。每点特征[1,4]、[3,2]、[0,5]逐维最大得到[3,5]，两维可来自不同点，并非某个真实点。

分类要求排列不变；逐点分割要求排列等变：点列表重排，输出标签同样重排。可把全局特征拼回每点局部特征再预测。基本PointNet局部邻域建模有限，层次化方法额外组织邻域。

## 4. 点集重建为何不用逐索引MSE？

点列表索引不代表固定对应位置。平方Chamfer先对P中每点找Q最近点的平方距离并平均，再反向做同样计算，相加。

P={0,2}、Q={0,3}：正向平均.5、反向平均.5，和为1。双向避免单向只覆盖目标一部分，但不约束一一匹配，对密度和覆盖仍有限。不同资料的平方/距离、均值/求和要核对；运输匹配损失另有约束与成本。

## 5. SDF把形状存成查询函数

单位球SDF=norm([x,y,z])−1，本笔记内部负、表面零、外部正：中心−1，(1,0,0)为0，(2,0,0)为1。

x²+y²+z²−1也有同样零表面，但不等于真实距离。神经隐式场用网络近似占据或距离，可能以三维标签或可微渲染监督；连续输入不保证无限精度。展示网格还需采样与等值面提取。

## 6. NeRF如何从场得到像素？

输入位置与观察方向，预测密度sigma和颜色c。相机射线r(t)=origin+t*direction，沿线取样，按前后遮挡合成：

```text
alpha_i = 1−exp(−sigma_i*delta_i)
T_i = 前面各段(1−alpha)的乘积
weight_i = T_i*alpha_i
pixel = sum(weight_i*color_i) + 剩余透射率*背景
```

密度与段长相乘才决定该段alpha；方向单位与步长须一致。两段alpha均.5，前红、后蓝、黑背景：权重为.5、.25、背景.25，颜色(.5,0,.25)。倒过来则(.25,0,.5)，不是简单平均红蓝。

原始场景级NeRF通常用多视图图像与相机信息，通过渲染像素误差训练场，梯度穿过颜色、密度和透射关系。可渲染场不等于准确物理材质或碰撞动力学；本例只验证局部渲染公式。

## 7. Gaussian Splatting与物体结构

3D高斯表示中心、空间协方差、透明度与外观，投影后混合成图。它是显式可优化场景表示，不等于隐式MLP查询，也不是固定圆形点。需结合可见性、排序与表示预算。

椅背、椅座与椅腿的部件关系，抽屉的运动约束，都不是一团坐标自动说明的。部件、关系图和层级表示补充几何，使重建与机器人操作相接。
