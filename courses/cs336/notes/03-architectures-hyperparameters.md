## 1 参数 架构与超参数

三个概念先分清：

| 对象 | 回答的问题 | 例子 |
|---|---|---|
| 架构 | 用哪些运算，怎样连接 | 注意力后接前馈网络，配合残差与归一化 |
| 超参数 | 怎样设置结构与训练过程 | 层数、向量宽度、头数、学习率 |
| 参数 | 固定结构中哪些数字通过训练调整 | embedding、投影矩阵、归一化缩放 |

同一架构可以有不同尺寸；同一组超参数也可以训练出不同权重。训练通常调整矩阵里的数值，不是在每一步自动选择有多少层。

## 2 从 token 到下一项概率

现代自回归 Transformer 的整体路径为：

```text
文本 → tokenizer → token ID
                     ↓
                 embedding
                     ↓
           多个 Transformer block
                     ↓
                最终归一化
                     ↓
              输出投影得到 logits
                     ↓
              softmax 得到概率
```

设 B 是样本数、S 是序列长度、d 是模型宽度、V 是词表大小：

| 阶段 | 形状 | 含义 |
|---|---|---|
| 输入编号 | `(B,S)` | 每个位置一个 token ID |
| embedding 输出 | `(B,S,d)` | 每个位置一个 d 维向量 |
| block 输出 | `(B,S,d)` | 形状保留，内容融合前缀信息 |
| 输出 logits | `(B,S,V)` | 每个位置对 V 个候选给一个分数 |
| softmax 概率 | `(B,S,V)` | 沿候选轴归一化 |

Logit 是尚未归一化的分数，可以为负，不要求加起来等于 1。某个位置的分数 z 转为概率：

```math
p_j=\frac{\exp(z_j)}{\sum_{k=1}^{V}\exp(z_k)}.
```

**Softmax 沿词表候选轴计算，而不是沿样本或序列轴。** 输出投影通常把 d 维表示映射到 V 维；embedding 与输出权重可以共享或独立，取决于配置。

### 一次输出对应哪个目标

教学例子把 A、B、C、D 各当一个 token：

```text
输入：A B C
目标：B C D
```

位置 A 的输出预测 B；位置 B 的输出预测 C；位置 C 的输出预测 D。当前位置可以读取自己及之前输入，因为当前 token 是下一项预测的前缀成员。

训练时真实文本已知，但必须限制每个位置能读取的范围。生成时对已知前缀计算输出，常取最后一个位置的分布选择下一项，加入前缀后继续。

## 3 一个 block 中的两种信息处理

第 4 页的现代 block 包含因果多头注意力、逐位置前馈网络、归一化与残差。可以先记住两种核心变换：

- **注意力**：一个位置从允许访问的位置聚合信息。
- **前馈网络**：在每个位置内部转换特征，各位置共用同一套权重。

前馈网络本身通常不直接让两个 token 位置交换信息；但它的输入已经可以包含之前注意力收集的上下文。

**形状相同不代表数值或含义没有变。** 输入和输出都为 `(B,S,d)`，内部仍可以经历投影、上下文汇总、非线性与残差相加。

## 4 注意力怎样计算

本节补充课件结构图所需的基本机制，采用行向量约定；原始机制可对照 [Transformer 原论文](https://arxiv.org/abs/1706.03762)。

### Q K V 是从输入学出来的三种表示

忽略批次与多头，输入 X 为 `(S,d)`：

```math
Q=XW_Q,\qquad K=XW_K,\qquad V=XW_V.
```

Q 是查询表示，K 是用于匹配的表示，V 是用于汇总的内容。三者不是人工标注的语义类别；权重通过训练学习。

Q、K 的每行维度记为 d_k，V 的每行维度记为 d_v：

```math
Z=\frac{QK^{\mathsf{T}}}{\sqrt{d_k}}+M,
\qquad A=\mathrm{softmax}_{\mathrm{keys}}(Z),
\qquad O=AV.
```

| 对象 | 形状 | 含义 |
|---|---|---|
| Q | `(S,d_k)` | 每个查询位置的表示 |
| K | `(S,d_k)` | 每个被查询位置的匹配表示 |
| QKᵀ | `(S,S)` | 各查询与各 key 的匹配分数 |
| A | `(S,S)` | 每行在允许 key 位置上的权重 |
| V | `(S,d_v)` | 各位置提供的内容 |
| O | `(S,d_v)` | 各查询位置汇总后的内容 |

缩放 d_k 的平方根，可以在一定初始化假设下控制点积随维度增大的尺度，避免分布过早变得极端。它不是严格保证训练稳定的充分条件。

### 因果掩码防止读取未来

三位置输入 A、B、C，对应允许读取关系：

```text
           key A  key B  key C
query A      ✓      ×      ×
query B      ✓      ✓      ×
query C      ✓      ✓      ✓
```

M 在允许处为 0，禁止处在理想表达中为负无穷；加到 logits 后再做 softmax，使禁止位置的权重为 0。不能把禁止项设为普通的分数 0，因为 softmax 会给它非零权重。

训练虽然能在一次张量计算中并行处理多个位置，各位置仍有不同可见范围。**并行计算不意味着允许看未来。**

### 一行注意力手算

教学例子设缩放与掩码后的两个可见位置分数是 `[ln(2),0]`。取指数得到 `[2,1]`，归一化为 `[2/3,1/3]`。

若两个 value 向量是 `[1,0]` 与 `[0,3]`：

```math
o=\frac{2}{3}[1,0]+\frac{1}{3}[0,3]=\left[\frac{2}{3},1\right].
```

注意力是加权汇总，不一定只选一个位置。这里的权重也不是下一个 token 的生成概率：前者分布在 key 位置上，后者分布在词表候选上。

### 多头

多个头使用不同投影，分别完成上述汇总，再拼接并通过输出矩阵变换。常见简化配置是 h 个头、每头宽度 d/h，合起来宽度为 d。

“头数乘每头维度等于模型宽度”是常见尺寸选择，不是注意力公式的数学要求。投影矩阵可以改变总投影维度，随后再映射回残差所需的 d。

## 5 残差与 Pre-Norm

课件第 10–13 页比较归一化放置位置。残差是把输入直接加回变换结果：

```math
y=x+F(x).
```

这使原输入有一条直接路径，分支学习对它的修正。相加的形状要兼容。

**Post-Norm：**`y=Norm(x+F(x))`，相加后的主路径也经过归一化。

**Pre-Norm：**`y=x+F(Norm(x))`，归一化在分支输入上，主残差路径不直接经过该归一化。

现代串行 block 的一种写法是：

```math
h=x+\mathrm{Attention}(\mathrm{Norm}_1(x)),
\qquad y=h+\mathrm{FFN}(\mathrm{Norm}_2(h)).
```

课件结合梯度传播与尖峰现象讨论 Pre-Norm 的稳定性优势。它不能免除学习率、初始化与其他训练设置的检查。课件还介绍分支输出归一化或双重归一化，关键是判断归一化是否直接影响主残差路径，不只看它叫“前”还是“后”。

## 6 LayerNorm 与 RMSNorm

课件第 14–19 页讨论归一化形式。这里对每个 token 的特征向量分别归一化，通常不沿整个 batch 计算统计。

### LayerNorm

对 d 维向量，均值与方差是：

```math
\mu=\frac{1}{d}\sum_{i=1}^{d} x_i,\qquad
\sigma^2=\frac{1}{d}\sum_{i=1}^{d}(x_i-\mu)^2.
```

典型输出为：

```math
y_i=\gamma_i\frac{x_i-\mu}{\sqrt{\sigma^2+\epsilon}}+\beta_i.
```

gamma 是可学习缩放，beta 是可学习偏移，有些配置去掉偏移。epsilon 避免除以极小数。

### RMSNorm

均方根 RMS 使用平方的平均：

```math
\mathrm{RMS}(x)=\sqrt{\frac{1}{d}\sum_{i=1}^{d} x_i^2},\qquad
y_i=\gamma_i\frac{x_i}{\sqrt{\frac{1}{d}\sum_{j=1}^{d}x_j^2+\epsilon}}.
```

它通常不减均值，也不添加 beta。课件用向量范数作简写；实际 RMS 定义包含维度平均，不能直接把未平均的二范数当成 RMS。

教学例子 `[3,4]`，暂设 epsilon=0、gamma=1、beta=0：

- LayerNorm：均值 3.5，标准差 0.5，得到 `[-1,1]`。
- RMSNorm：RMS=`sqrt(12.5)`，得到约 `[0.8485,1.1314]`。

**RMSNorm 不保证输出均值为 0。** 学习到的缩放也可能改变归一化后的尺度。

课件强调 RMSNorm 较少的操作与数据访问可能带来收益，但 FLOPs 比例小不等于运行时间影响小，要结合第二讲的带宽分析理解。不能只看数学式认定所有实现都有固定加速比例。

## 7 FFN 激活与 SwiGLU

课件第 20–26 页比较激活和门控。普通无偏置 FFN 常写为：

```math
\mathrm{FFN}(x)=\phi(xW_1)W_2.
```

W1 将 d 维扩展到 d_ff，逐元素非线性 phi 之后，W2 再映射回 d。只有相连的线性矩阵仍可合并成一个线性变换，非线性改变了表达能力。

| 激活 | 定义或理解 | 特点 |
|---|---|---|
| ReLU | `max(0,x)` | 负数变为零 |
| GELU | `x Φ(x)`，Φ 为标准正态累计分布函数 | 平滑地调整不同输入 |
| SiLU 或 Swish | `x sigmoid(x)` | 平滑的输入相关缩放 |

SwiGLU 使用两路输入投影，逐元素相乘后再投影：

```math
\mathrm{SwiGLU}(x)
=\bigl(\mathrm{SiLU}(xW_g)\odot(xW_u)\bigr)W_d.
```

两路先得到形状相同的向量，门控路经 SiLU，再与另一条路逐元素相乘。这里的门控不是从多个专家中选择专家，也不要求门值落在 0 到 1。

课件展示一些支持门控 FFN 的实验，同时保留不同激活选择。工作模型不必须采用 SwiGLU，具体效果仍需验证。

### 门控为什么常用较小中间宽度

普通无偏置 FFN 有两张主要矩阵，参数约 `2d d_ff`；门控 FFN 有三张，参数约 `3d d_ff`。

要匹配普通 `d_ff=4d` 的参数规模：

```math
2d(4d)=3d\,d_{\mathrm{ff}}^{\mathrm{gated}},\qquad
d_{\mathrm{ff}}^{\mathrm{gated}}=\frac{8}{3}d.
```

这解释了课件中的 2/3 缩放。它是相近参数预算的比较，不是所有模型必须遵守的规则；实际常按硬件友好的倍数调整宽度。

## 8 串行与并行 block

第 27–29 页比较两种结构。

串行：注意力更新后，FFN 使用更新后的表示。并行变体则让注意力和 FFN 从同一个输入分别计算，再把两个结果与残差合并。

简化表达为：

```math
y=x+\mathrm{Attention}(\mathrm{Norm}(x))
+\mathrm{FFN}(\mathrm{Norm}(x)).
```

分支归一化是否共享取决于实现。并行结构可能便于融合投影和减少等待，但它改变了计算依赖，并非只是在硬件上把原串行结构同时执行。课件指出串行结构仍很常见。

## 9 位置表示与 RoPE

第 30–35 页比较固定正弦、可学习绝对位置、相对位置与旋转表示。基本注意力仅按内容匹配，没有自行明确“第几个位置”；因果可见性也不能代替全部位置信息。

绝对位置方案可以将位置向量加到 token 表示上。RoPE 通常在注意力的 Q、K 上按位置做旋转，而不是简单给输入加一个向量。

### 二维旋转的含义

一对坐标按角度 theta 旋转：

```math
\begin{bmatrix}x'_1\\x'_2\end{bmatrix}
=\begin{bmatrix}\cos\theta&-\sin\theta\\
\sin\theta&\cos\theta\end{bmatrix}
\begin{bmatrix}x_1\\x_2\end{bmatrix}.
```

教学例子 `[1,0]` 旋转 90 度变为 `[0,1]`，向量长度不变。RoPE 给不同坐标对分配不同频率，再按位置确定旋转角。

对位置 m 的 query 与位置 n 的 key：

```math
(R_mq)^{\mathsf{T}}(R_nk)=q^{\mathsf{T}}R_{n-m}k.
```

点积中的显式位置因素由两位置的差决定。共同平移位置会共同旋转，保持相应点积不变。这里描述旋转机制；实际 q、k 自身还取决于文本与前层上下文。

课件将 RoPE 应用于各次注意力的 Q/K。旋转维度、频率、扩展设置可以变化，也不自动保证超出训练长度的效果。

## 10 尺寸超参数怎样取舍

第 36–47 页围绕模型宽度、中间层宽度、头维度、深宽比和词表讨论。

### FFN 宽度

普通 FFN 的 `d_ff≈4d` 与门控的 `d_ff≈8d/3` 是常见基线。课件也列出明显例外，强调可工作的范围和经验不等于唯一最优。

### 头数与头维度

常见 `h×d_head=d`。如果总投影维度固定，增加头数意味着每头维度缩小，不是免费增加一份完整模型。

若总投影维度与 d 不同，Q/K/V 和输出矩阵需要相应变化。课件第 43 页列出此类例外；表中个别数字与所列比例并不自洽，本文不将该表全部当成可直接采用的模型配置。

### 深与宽

更多层增加串行依赖；更宽的层通常增加矩阵尺寸与参数。对简化密集层，参数随 `Ld²` 的量级变化，不能把宽度翻倍只看成参数翻倍。

课件将深宽选择同时联系效果、延迟与并行，避免追求单一比例。它列出的经验范围用于观察，不是所有预算的最优保证。

### 词表大小

较大 V 可能使文本更紧凑，但 embedding 和输出候选成本也会增加。课件用不同语言覆盖的模型比较词表规模，连接第一讲的取舍。

固定 d 时，一张 embedding 表有 `Vd` 个参数；输出矩阵未共享时也可能有相应规模。不同语言与数据分布需要单独评价，而不能仅凭词表条目数量判断能力。

## 11 Dropout 与权重衰减

第 48–51 页讨论大规模预训练中的正则化。Dropout 在训练中随机屏蔽部分激活并进行相应缩放，正常推理时通常关闭。课件列出的许多现代模型不使用预训练 dropout，但不是对所有模型与任务的通用建议。

Weight decay 则在更新中对权重施加衰减。它不仅可能影响过拟合，也影响参数尺度、优化轨迹以及与学习率计划的关系。

**数据很多不能推出“模型不可能记忆”，也不能推出“所有正则化都没用”。** 课件的重点是观察具体训练配方，而不是机械套用小数据任务的解释。

## 12 Softmax 与稳定性

第 52–56 页讨论损失尖峰与分数尺度。指数函数会放大分数差异，过大数值可能溢出。计算 softmax 的常见数值方法是减去本行最大值：

```math
\mathrm{softmax}(z)_i
=\frac{e^{z_i-m}}{\sum_j e^{z_j-m}},\qquad m=\max_j z_j.
```

这不改变概率，因为分子分母同时乘了相同因子。它改善直接指数运算的数值行为，但不自动解决学习到的分数过大、梯度尖峰等所有问题。

### z-loss

定义输出分数的归一化量 `Z=Σ exp(z_i)`。课件第 54 页给出的辅助约束，在最小化负对数似然的约定下为：

```math
\mathcal{L}_{\mathrm{total}}=\mathcal{L}_{\mathrm{NLL}}+\alpha(\log Z)^2.
```

它鼓励 log Z 接近 0，限制输出分数的共同偏移。Softmax 本身对所有 logits 加同一常数不变，而 log Z 会改变；这帮助理解为何概率相同也可能有不同的数值尺度。

计算 log Z 可使用稳定的 logsumexp，但不能把“减去最大值后的归一化量”直接当成原始 Z，因为要把偏移加回去。

### QK-Norm

在点积前对 query 和 key 使用归一化，以控制注意力分数的尺度。它与 block 输入的 Pre-Norm 位置和对象不同，不应混为一谈。归一化形式、轴与缩放由配置决定。

### Soft-capping

课件第 56 页使用平滑限制：

```math
z'=c\tanh(z/c),\qquad c>0.
```

将有限分数平滑限制在 `(-c,c)` 中。它改变分数差异与梯度，可能影响表达与效果；不能无条件替代其他稳定化措施。因果禁止位置也不能经此变成普通有限分数，掩码仍需保证禁止权重为零。

## 13 注意力变体与推理成本

第 57–66 页介绍 GQA/MQA、稀疏或滑动窗口及交替结构，第四讲将继续扩展注意力替代方案。

### KV cache 为什么存在

自回归生成新 token 时，既有前缀的 key/value 可以缓存，避免每步全部重新投影。缓存会随层数、序列长度、样本数与 KV 头维度增加。

生成时“沿时间逐步产生新 token”和“一个位置内部可并行计算多个头”不矛盾。KV cache 减少重复工作，但仍要存储与读取历史数据。

### MHA MQA GQA 的区别

| 方案 | Query 头 | Key/Value 头 | 主要取舍 |
|---|---|---|---|
| MHA | 多个 | 通常每个 query 头对应独立 KV 头 | KV 表示较丰富，缓存较大 |
| MQA | 多个 | 一组共享 KV 头 | 显著减少缓存，效果可能受影响 |
| GQA | 多个 | 少于 query 头的多个 KV 组 | 在共享程度与效率间折中 |

MQA 共享一个 KV 头不表示 key/value 只有一个标量。每个头仍有自己的向量维度。固定其他条件时，缓存大小约随 KV 头数变化；不能认为 query 头也全部被删除。

### 滑动窗口与交替层

窗口注意力限制每个位置直接访问附近 w 个位置，使相应注意力计算可从序列平方量级降为约 `Sw`。代价是单层直接可见范围缩小，多层传播可以扩大间接影响范围。

课件还展示局部层与全局层交替：局部层降低成本，全局层保留直接跨较远位置的连接。不同位置表示和混合方案需要验证，不代表任意删掉连接都不影响效果。

## 14 统一理解架构选择

现代 Transformer 的许多选择同时服务三个目标：

| 目标 | 相关设计 | 要检查什么 |
|---|---|---|
| 表达与效果 | 注意力、门控 FFN、位置表示 | 相同预算下的损失与任务效果 |
| 稳定性 | 残差、归一化、分数尺度控制 | 梯度、激活与损失尖峰 |
| 系统效率 | 无偏置、RMSNorm、KV 共享、局部注意力 | 内存、带宽、吞吐与延迟 |

架构与训练设置相互影响。采用一组流行组件并不等于训练必然成功；理解计算关系，再用实验检验取舍，才是本讲的主线。

## 15 成组理解检查与实践

**A 整体路径**

1. 输入 `(2,3)`，模型宽度 4、词表大小 10，embedding 与输出 logits 的形状各是什么？
2. 一个位置产生 10 个 logits，是 10 个概率吗？还需要什么操作？
3. 为什么训练已知整段文本，仍不能让位置 A 读取未来位置 B 来预测 B？
4. 普通逐位置 FFN 是否直接混合不同 token？哪种组件负责跨位置汇总？

**B 组件机制**

1. Pre-Norm 与 Post-Norm 中，哪个让主残差路径直接经过归一化？
2. 为什么 RMSNorm 不一定得到均值为零的向量？
3. 注意力权重 `[2/3,1/3]` 与两个 value `[1,0]`、`[0,3]` 怎样得到输出？
4. RoPE 通过什么方式把位置引入 Q/K？相对位置关系体现在哪里？

**C 超参数与成本**

1. 为什么门控 FFN 使用 `8d/3` 可与普通 `4d` FFN 的矩阵参数数相近？
2. KV 头数从 8 减到 2、其他条件不变，缓存的相应部分约变成多少？Query 头必须同时减为 2 吗？
3. 减去 logits 最大值和 soft-capping 是否都保持 softmax 概率不变？
