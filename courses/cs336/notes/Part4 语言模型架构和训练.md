## 1.2 多头注意力机制
### 单头注意力的做法与局限
单头注意力的计算基于缩放点积注意力机制。
对于输入序列 X（形状为 $[batchSize, seqLen, d_{model}]$ ，首先通过三组权重矩阵将其映射为查询（Q）、键（K）、值（V）：
$$Q = XW^Q, \quad K = XW^K, \quad V = XW^V$$
其中 $W^Q,W^K,W^V$ 的形状均为 $[d_{model}, d_{model}]$ ，随后计算注意力输出：
$$Attention(Q, K, V) = softmax(\frac{QK^T}{\sqrt{d_k}})V$$
这里 $d_k = d_{model}$ ，缩放因子 $\sqrt{d_k}$ 用于防止点积结果过大导致梯度进入饱和区。

单头注意力的局限在于，它只能计算一种“查询-键-值”关系，如同只用一双眼睛观察。这导致模型难以同时捕获语法结构、语义关联、长程依赖等多种模式，注意力分布往往过于分散，无法聚焦于多个重要的子空间。因此，普遍做法是将注意力机制重复多次，让每个头学习不同的子空间表示，最后将结果合并。
### 多头注意力的设计思想
step1：多头注意力
对于输入 $Q, K, V$ （形状均为 $[batchSize, seqLen, d_{model}]$ ，首先将其拆分为 h 个头，通过重塑和转置，将头维度提前：
```Python
Q = Q.reshape(batch_size, seq_len, h, d_k)   # [bs, seq_len, h, d_k]
Q = Q.transpose(1, 2)                        # [bs, h, seq_len, d_k]
```

step2：并行计算每个头的注意力
对于第 i 个头，独立执行缩放点积注意力：
$$Head_i = Attention(Q_i,K_i,V_i) = softmax(\frac{Q_iK_i^T}{\sqrt{d_k}})V_i$$
其中 $Q_i, K_i, V_i$ 的形状均为 $[batchSize, seqLen, d_k]$ 。

step3：拼接与最终线性变换
$$MultiHead(Q, K, V) = Concat(Head_1, ..., Head_h)$$
拼接后的形状为 $[batchSize, seqLen, h \times d_k] = [batchSize, seqLen, d_{model}]$。最后通过一个输出投影矩阵 $W$ （形状 $[d_{model}, d_{model}]$ ）进行线性变换，得到最终输出：
$$Output = MultiHead(Q, K,V)W$$
#### 一些问题
Q：为什么需要多头而不是单头？
A：并行关注不同模式，每个头可学习不同注意力模式：
假设比喻：Head1：关注语法依赖（主谓宾）Head2：关注共指关系（代词指代）Head3：关注语义相似（同义词）。
同时可以提升表示能力，因为每头在低秩子空间（$d_k$ = 64）计算，比单头在高维空间更高效，多头合并相当于高秩矩阵分解，表达能力更强。
计算效率也更高，各头可并行计算，适合 GPU 加速。

Q：为什么要除以 $\sqrt{d_k}$ ？
原始论文推断 $\sqrt{d_k}$ 值较大时，点积的绝对值会变得很大，这会将函数推入梯度极小的区域，为了抵消这种影响，我们对点积进行 $\sqrt{d_k}$ 的缩放。
1. **保持方差稳定**：无论 $d_k$ 多大，输入 softmax 的值都在合理范围
2. **避免梯度消失**： softmax 的梯度保持有效值，反向传播顺畅
3. **稳定训练**：使模型对维度选择不敏感，原始论文使用 $d_k = 64$ （单头）依然稳定
## 1.3 层归一化（LayerNorm）与残差连接
### 归一化
**归一化是将数据按特定规则进行缩放**，使其落入统一的标准范围或分布的技术。在深度学习中，它主要指对神经网络中间层的激活值或权重进行变换，以稳定训练过程、加速收敛。
在概率论中，归一化为 $x_{norm} = (x - \mu) / \sigma$ 。

transformer 原始层的归一化：
$$LayerNorm(v) = \gamma \frac{v - \mu}{\sigma} + \beta$$
### 残差
残差（Residual）在深度学习中指的是残差连接（Residual Connection），也称为**跳跃连接**（Skip Connection），是连接神经网络层与层之间的"捷径"，让信息可以直接绕过某些层传递。
残差公式为：
$$Output = Input + Layer(Input)$$
### 层归一化和残差连接
原始 Transformer 论文中，层归一化（Layer Normalization） 和残差连接（Residual Connection） 是协同工作的核心设计，共同确保深层网络稳定训练。 原始论文中是先残差连接在进行归一化：
$$Output = LayerNorm(x + Sublayer(x))$$

层归一化：解决分布漂移、梯度不稳定的问题，标准化分布，加速模型收敛，防止梯度消失和梯度爆炸。
残差连接：确保梯度直接回传，至少保留恒等映射能力，提供稳定信息通路，解决分布不稳定，深层仍难训练的问题。
## 1.4 前馈网络（Feed Forward）与激活函数
### ReLU的应用位置
在编码器和解码器的每个层中，前馈网络的结构为：
$$ FFN(x) = max(0, xW_1 + b_1)W_2 + b2$$
一个合格的激活函数
- 必须是非线性，对于一个线性函数，无论多么深的神经网络，他始终是一个简单的神经网络，只能拟合简单的函数，多层网络会退化为单层线性模型，对于非线性函数，能增加网络的复杂性，学习复杂问题。
- 具有可微性，在定义域内几乎处处可微，支持梯度下降和反向传播，否则无法使用梯度下降来训练模型。ReLU在 x=0 处不可微，但实践中可以使用次梯度（subgradient），效果良好。
- 计算高效，一个激活函数在模型推理和训练中会被调用数十亿次，在高数量级下的运算下的计算成本不会太高。
# 2. Transformer 的现代变体
## 2.1 归一化
### 原始论文设计，后归一化
位置上：Post-LN
结构：子层 -> 残差连接 -> 层归一化
$$X = LayerNorm(X + Sublayer(X))$$
很快人们发现，将 LayerNorm 移至残差连接之前（即预归一化）能在多方面获得更好效果（Pre-LN）。
### 现代主流，预归一化
位置上：Pre-LN
结构：层归一化 -> 子层 -> 残差连接
$$X = X + Sublayer(LayerNorm(X))$$
它具有明显优势：**训练更稳定**，无需复杂的**学习率预热**，且适用于**极深网络**（100+ 层）。目前已成为 GPT-3、PaLM 等大模型的默认配置。
### 简化变体：RMSNorm
LayerNorm 计算均值和标准差的成本高，且对 Transformer 并非需要，基本上所有模型都改用RMSNorm，其核心变化是：直接去除了均值调整环节。
公式（去掉均值归一化，仅保留方差归一化）：
$$RMSNorm(v) = \gamma \frac{v}{\sqrt{\frac{1}{d} \sum_{i=1}^nv_i^2 + \epsilon}}$$
### 一些问题
Q：为什么残差中的LayerNorm不好（post-norm）？
A：**Post-Norm 的问题在于，加完残差之后，连直连路径上的信号也要经过一次归一化。** 层数很多时，梯度沿着直连路径往回传，仍然要经过每一层的归一化。Pre-Norm 把归一化移到计算分支里，给梯度留出一条可以直传的路径。

归一化新趋势：**双重归一化（Pre + Post Norm）**
这种设计的直觉是，**“如果遇到稳定性问题，到处撒一点 LayerNorm 往往能解决问题”**。尽管听起来缺乏理论优雅性，但该策略已被多次证明能在几乎不损害性能的前提下，显著提升深层 Transformer 的训练稳定性。

**设计哲学是“保持残差流的干净”**，无论是 Pre-Norm 还是双重归一化，背后的核心思想是 **“保持残差流的干净（Keep your residual stream clean）”**。在 Pre-Norm 架构中，输入 从模型底部直达顶部的残差连接形成了一条**无障碍的梯度高速通道**，使得反向传播时梯度能够无损流动，不会因层归一化对残差路径的反复缩放而衰减或爆炸。
## 2.2 前馈网络
原始Transformer的前馈网络结构包含带偏置的线性层->ReLU->第二个线性层。但当前主流实现（非门控单元版本）均**已移除所有偏置项（b）**。因为矩阵乘法就已经能满足模型运行了。另一个是优化稳定性。
$$FNN(x) = max(0,xW_1)W_2$$
FFN去除偏置项 b 的理由几乎和 RMSNorm 一致，去除偏置项的想法广泛适用，许多模型在大多数地方根本没有偏置项。

## 2.4 位置编码
### 绝对嵌入（Absolute Embedding）
正弦嵌入（Sine Embeddings），就是一种绝对位置编码。

它为序列中**每个位置分配唯一编码向量**，与词嵌入相加：
$$Final Embedding = Token Embedding + Positional  Embedding$$
但是它是**绝对位置感知**，无法直接建模相对距离，并且**长序列性能会衰减**，位置编码差异随距离增大而模糊。正弦嵌入理论上可计算任意位置，具有一定的外推能力，但实际长序列性能会显著衰减。
### 相对嵌入（Relative Embedding）
核心思想是建模 token 间的相对距离，而非绝对位置，不再编码绝对位置，而是在**注意力计算中显式引入相对位置信息,在注意力计算中添加向量**，让模型关注 token 间距离。

旋转位置编码就是一种相对嵌入。
目前绝大多数**先进模型都采用旋转位置编码**，其设计直觉与正弦余弦相同——需要覆盖不同频率范围以获取高低频信息。旋转本质是**矩阵乘法**。由于θ和m值固定，这相当于用**固定矩阵乘以向量**。

理解部分：
当我们对 Q、K 矩阵都进行旋转后：
$$Q_1 = R(m) \cdot Q$$
$$K_1 = R(n) \cdot Q$$

之后：
$$Attention(Q,K,V) = softmax(\frac{QK^T}{\sqrt{d_k}})V$$
$$Q_1K_1^T = R(m)R(n)^T \cdot QK^T = R(m)R(-n) \cdot QK^T = R(m-n) \cdot QK^T$$
我们为不同位置的token都乘以不同角度的旋转矩阵在计算注意力的时候就会出现 $R(m-n)$，这就代表两个**token的相对位置信息**。

二维旋转是直观的，RoPE 提出的解决方案是将**高维向量分割为多个二维子块**，在每个二维子空间**内独立实施旋转操作**：

## 2.5 注意力机制的变体
在**传统的注意力机制中**，我们会为**每个头来分配一个 Q、K、V 矩阵**，对于每个头都有**独属**于自己的 Q、K、V 矩阵。 对于 $h_1$ 来说，会为它分配 $Q_1$、$K_1$、$V_1$ 是三个**不同**的矩阵。

KV cache
![[Pasted image 20261104163258.png]]

我们生成文本时，记住我们生成一个 token，然后 Transformer 读取该 token 并处理它，接着我们可以得到下一个 token 的分布，然后我们自回归地一次一个 token 地执行操作。通过这样做，我们无法并行化生成过程，我们需要为每个新 token 逐步进行。我们会存储历史计算的 K 和 V 的值，这样我们在生成新的token的时候就不用重复计算 K 和 V 的值，这称为 KV cache。

传统多头注意力机制（MHA）会为每个头分配一个 Q、K、V 矩阵，对于每个头都有独属于自己的 Q、K、V 矩阵。
### 多查询注意力（Multi Query Attention，MQA）
则对其进行了优化，它的主要改进点是共享 K、V 矩阵，即多个头共享同一个 K、V 矩阵，Q 矩阵则不共享。这样减少了存储 KV 矩阵的显存压力。
### 分组查询注意力机制（Grouped Query Attention，GQA）
GQA（分组查询注意力）在此基础上稍作调整：不再采用多查询配单键的模式，而是按一定倍数减少键的数量。这样可以在推理时间表现和模型表达能力之间取得平衡。因为从多头注意力直接切换到多查询注意力可能过于激进。
也就是说，GQA 觉得 MQA 和 MHA 太极端了，它选择站中间，通过 GQA，Qwen 系列模型在保持较高推理效率的同时，减少了KV缓存的冗余计算，例如，Qwen2-32B 的 KV 缓存显存占用降低至标准多头注意力的62%。

**为什么 GQA 如此有效？**
GQA 不仅节省了内存，更关键的是它解决了自回归推理阶段的算术强度（Arithmetic Intensity）瓶颈。
在自回归生成中，每步都需要从 KV Cache 中读取所有历史 Key 和 Value 进行增量计算。此时内存访问量剧增，而计算量不变，导致**算术强度大幅下降**，GPU 大部分时间在等待数据搬运。
算术强度大致为：
$$\frac{1}{N/D+1/B}$$

具体怎么来的？
对于 KV Cache 的自回归解码，每一步，每条序列送入 1 个新 token，用它预测下一个 token。
所以，

| 每个解码步       | 数量级    | 为什么                                          |
| ----------- | ------ | -------------------------------------------- |
| 线性层计算       | $BD^2$ | $B$ 个新位置，各用一次大小约为 $D\times D$ 的权重            |
| 读取模型权重      | $D^2$  | 同一套权重供整个 batch 使用                            |
| 读取 KV cache | $BND$  | $B$ 条序列，每条有 $N$ 个历史位置，每个位置的 K、V 合起来是 $D$ 的量级 |
$$ 算术强度 = \frac{BD^2}{D^2+BND}$$
所以对于 MQA/GQA ：通过让多个查询头共享同一组 Key/Value，减少的是读取 KV cache 的消耗，这相当于**用更多的查询头来“摊薄”内存访问的代价**，从而在硬件层面大幅提升吞吐量。
### 稀疏 / 滑动窗口注意力
2019年，OpenAI发表了一篇精彩论文，探讨如何构建更长注意力的模型。他们提出的解决方案是**设计稀疏注意力模式**，不是关注整个序列，而是聚焦于每个分块的局部窗口，再辅以对角线等注意力模式来跨区块传递信息。通过这种稀疏或结构化注意力，可以在表达能力和运行效率之间取得平衡。

### 现代滑动窗口注意力的混合范式
Cohere Command A **的具体配置为 3 层滑动窗口（窗口 4,096）+ 1 层全局注意力。OLMo 2 则在每 4 层中的第 4 层及最后一层使用全局注意力**。Qwen 3.5 将 Gated DeltaNet（线性注意力）与标准注意力以约 3:1 的比例交替排列，Gated DeltaNet 结合了 Mamba2 的门控衰减机制与 Delta 规则。

### MLA：DeepSeek 的多头潜在注意力机制
MLA（Multi-head Latent Attention，多头潜在注意力）是 DeepSeek 引入的创新注意力架构，通过低秩联合压缩技术显著降低推理时的KV缓存需求，在保持性能的同时大幅提升效率。
![[Pasted image 20261105092253.png]]

传统的 Transformer 模型通常采用多头注意力机制（MHA），但在生成过程中，其庞大的键值（KV）缓存会成为限制推理效率的瓶颈。MQA、GQA 做到了更小的 KV 缓存量，但其性能始终比不上 MHA。

MLA 作为 DeepSeek 模型中的一个重要组件，扩展了多头注意力机制，通过引入**潜在表示**来增强模型的表达能力。MLA的本质是对 **KV（Key-Value，一种缓存机制）的有损压缩**，提高存储信息。
主要分为两步：
**输入映射到潜在空间**：给定输入（其中 n 是序列长度， d 是特征维度），通过映射函数 f 将其投影到潜在空间。这样我们在存储 KV 的时候就能大大减小显存的占用。
$$c_K = x \cdot W_K^{down} \in R^{L\times r}$$
$$c_V = x \cdot W_V^{down} \in R^{L\times r}$$
**在注意力计算前，将缓存的压缩 KV上投影回原始空间：**
$$K = c_K \cdot W_K^{up} \in R^{L \times (h \cdot d_h)}$$
$$V = c_V \cdot W_V^{up} \in R^{L \times (h \cdot d_h)}$$

### DSA（DeepSeek Sparse Attention）deepseek 稀疏注意力机制
DeepSeek Sparse Attention（DSA）是 DeepSeek-V3.2-Exp 引入的细粒度动态稀疏注意力机制，也是头一个用 deepseek 命名的技术。通过智能筛选关键信息将长上下文推理成本降低 60-70%，同时几乎不损失模型质量。
#### Lighting Indexer（闪电索引器）
为每个 Query Token 快速扫描历史 Token，计算"重要性代理分数"，它是一个轻量级的网络，使用一个远少于主模型的注意力头，以 FP8 低精度运行，快速扫描所有历史 token，计算得分。
#### 细粒度 Top-k 选择
基于索引分，为每个Query动态构建专属的 Top-k 集合，常 k=2048，与序列长度L无关，复杂度强制降为 $O(L·k)$，传统注意力的复杂度为 $O(L^2)$。

预训练看似是最不需要正则化的场景——因为**预训练通常只进行一个训练周期**，由于数据量过大甚至无法完整遍历所有数据，**单轮训练**几乎不可能导致过拟合。这似乎构成了不需要正则化的充分理由。但实际情况却比较复杂。早期研究大量使用dropout，权重衰减也被广泛采用。虽然现在很多团队不再详细发布训练超参数，但 dropout 已逐渐失宠，而权重衰减**仍被持续使用**。
# 4. 模型的稳定性
随着模型规模不断扩大，训练时间持续延长，这类稳定性问题愈发明显。
Transformer 中最容易出问题的就是 softmax 函数，问题根源在于：指数运算可能导致数值异常，除法运算可能产生除零错误。
Transformer 中存在两个 softmax 模块：一个是末端输出层的 softmax，另一个是自注意力机制中的 softmax。
- 自注意力 softmax：计算注意力权重时，logits（$QK^T$）可能过大，导致梯度损失。
- 输出层 softmax：生成分布时，logits 可能爆炸，使交叉熵损失不稳定。

## 4.1 z-loss 技术：解决输出层的 softmax
核心目标是防止 softmax 分母（归一化因子）过大或过小，从而稳定训练过程。
$$\mathcal{L}_{z-loss} = \lambda \cdot \log^2 Z$$

其中：
$Z$ ：softmax 的归一化因子（partition function），$Z = \sum_{i=1}^V exp(z_i)$
$\lambda$：权重系数
$z_i$ ：logits（未归一化分数）

总损失函数：
$$\mathcal{L}_{total} = \mathcal{L}_{cross-entropy} + \lambda \cdot \log^2 Z$$
它的目的是让 softmax 归一化器保持在良好的区间内，当 $z(x)$ 接近 1（或 logz 接近 0）时，可以认为 softmax 处于良好状态。
## 4.2 解决注意力层的 softmax
$$Attention(Q,K,V) = softmax(\frac{QK^T}{\sqrt{d_k}})V$$
标准流程是：
$$Q = W_q(x) \quad K = W_k(x) \quad logits = \frac{QK^T}{\sqrt{d_k}}$$

我们现在让查询向量和键向量通过层归一化层：
$$Q = LayerNorm(W_q(x)) \quad K = LayerNorm(W_k(x)) \quad logits = \frac{QK^T}{\sqrt{d_k}}$$
在稳定性干预措施中，最吃惊的就是**层归一化惊人**的有效性。我们见证了层归一化从仅出现在模块前端，发展到覆盖非残差组件的首尾两端，现在又拓展到 Q 和 K 分量中。至少在提升**稳定性**方面，层归一化在几乎不影响性能的前提下展现出了惊人的效果。
在训练过程中会应用LayerNorm。**在推理阶段LayerNorm还会保留**。因为LayerNorm已经学习了参数，它的完整作用是对激活值进行归一化处理，然后按特定尺度进行缩放。如果移除这个步骤，会对模型造成巨大改变，模型将无法处理那些未归一化的激活值。
## 4.3 软截断
软截断（Soft-clipping）技术，也称为 logit-capping 或 tanh-scaling。
核心思想是：在内积运算后、softmax 之前，通过 tanh 函数动态压缩 logits 的极端值，使其保持有界。

标准缩放点积：
$$logits = Q \cdot K^T / \sqrt{d_k}$$
可能范围：$(-inf, inf)$

软截断（Gemma2/OLMo2采用）：
$$logitsClipped = cap \cdot tanh(logits/cap)$$
在完成自注意力机制的内积运算后，将其通过软截断的softmax函数处理。具体来说就是使用上面这个公式：以 logits 作为输入，**里面先除以软截断值，外面再乘以软截断值**。
