# Does Reinforcement Learning Really Incentivize ReasoningCapacity in LLMs Beyond the Base Model?
标题：强化学习真的能让大语言模型获得超越基础模型的推理能力吗？

针对 RLVR（带可验证奖励的强化学习，比如让模型解数学题，答案正确就给予奖励；让模型写程序，通过测试就给予奖励），作者关注的是：训练后成绩提高，究竟多少来自新的推理能力，有多少来自更容易生成原本就能生成的正确解法。

论文全文围绕着 pass@k 展开，这个指标主要衡量了模型是否完全不会这道题。
pass@k 的意思是：对一道题生成 k 个答案，其中至少有一个正确，就算这道题通过；然后在整个题集上取平均。

$$P(\text{尝试 }k\text{ 次至少答对一次})=1-(1-p)^k$$

**论文主要的观察是：小 $k$ 时 RL 模型占优，较大 $k$ 时基础模型经常追上甚至超过它。**

作者分出了四种情况（其中“能解出”表示：在指定的采样次数内，至少出现一次正确答案）：

| 基础模型 | RL 模型 | AIME24（1024 次） | MATH500（128 次） |
| ---- | ----- | -------------- | -------------- |
| 能解出  | 能解出   | 63.3%          | 92.4%          |
| 能解出  | 没解出   | 13.3%          | 3.6%           |
| 没解出  | 能解出   | 0.0%           | 1.0%           |
| 没解出  | 没解出   | 23.3%          | 3.0%           |

在 MATH500 上，RL 总共解出了 93.4% 的题，其中 92.4% 基础模型也能解。换算成“RL 解出的题里有多少基础模型也能解”为 98.9%。

接着作者以困惑度为指标去衡量，RL 模型解答文本在基础模型看来有多少“自然”。

公式是：

$\mathrm{PPL} =\exp\left(-\frac{1}{T}\sum_{t=1}^{T} \log P(y_t\mid x,y_{<t})\right)$

实验发现，RL 解答的 PPL 落在基础模型自身解答分布中较低的区域。作者据此认为：RL 生成的推理阶段，原本就受到基础模型的概率分布支持。

作者这里想表达的是，RL 生成的解法，基础模型原本就有可能生成，只是 RL 让它更容易被生成出来。但是“能预测别人写出的解法”和“能独立想出这份解法”，存在距离。类似于，看老师的证明，每一步都能跟上，但是合上答案未必自己能做出来。

然后针对“小 $k$ 提高、大 $k$ 却未必提高“这一核心现象展开，逐个检查可能的解释和适用范围，以及是否依赖特定的实验设置。

总结就是，在本文测试的模型、任务和 RLVR 训练设置下，RL 通常提高了单次作答的成功率，但在较大的采样预算下，解题覆盖率往往没有提高，甚至下降。

给的 RL 训练方法提示有
- 我们可以尝试先将数据集给原始模型跑 rollout，对于一次也答不上来的题目，可以先搁置一边，先训练那些能答上来的题目，然后再尝试将这些答不上来的题目重新测试。
- 评估时同时记录 pass@1、较大 $k$ 的 pass@k，去检查训练让模型更容易答对的同时，有没有让一些原本能偶然解出的题目变得更难解出。
