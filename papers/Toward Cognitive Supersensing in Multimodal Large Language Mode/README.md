## 1. 研究动机
当前多模态模型在开放词汇感知上已取得很大进展，但对视觉信息进行保持、变换和规则推断的能力仍然不足。现有方法常通过增加文本思维链（CoT）来增强推理，但将空间结构、几何细节和连续变化转述为线性文字时，可能存在信息损失，因此单纯增加文字推理未必能解决这些问题。

## 2. 数据集
作者整理 CogSense-Dataset-105k 作为训练数据，并建立 CogSense-Bench，把视觉认知分成五类。

| 维度     | 通俗理解                | 数据来源                               | 数据集规模（表 A1） | 基准题数（表 A2） |

| 流体智力   | 现场找规律，抽象规则归纳        | MaRs-VQA / PGM / RAVEN             |       29.4K |        276 |

前两类来自经典智力划分；后三类侧重结构理解、过程推演和注意操作。

### 2.1 数据构建
1. **搜集与人工筛选**：从已有数据集中挑出符合五类定义的题目。
2. **自动抽取和清洗**：扩展收集，统一原始数据。
3. **改写成多选 VQA**：统一为图像、问题、候选选项和答案。
4. **生成推理链**：教师模型根据任务专用提示生成过程与答案，过滤答案错误或含幻觉的样本。
5. **划分评测数据**：按类别比例抽取 1000 题，并从训练数据中移除被抽中的实例。
### 2. 2 人类基线
招募20名参与者，完成从基准中按类别比例抽取的100道多选题

## 3. 方法：教师推理链 → SFT + LVIP → RL
### 3. 1 第一阶段：请教师模型写过程和答案
给教师模型题目、图像和任务专用提示，让它生成推理链 $Z$ 与预测答案 $\hat y$。过滤 $\hat y\ne y$ 或存在幻觉的样本。
### 3. 2 第二阶段：SFT + LVIP
LVIP是挂在共享LLM主干上的两层MLP，输出为一个向量，训练它接近正确选项图像的特征。作者希望借此让模型在学文字推理时，也学到与正确答案有关的视觉表示。
SFT则是让模型学会推理链和自己内心想象的向量往答案向量上靠。
### 3. 3 RL
采用GFlowNet，希望模型以后更经常生成高分路径，同时保留多种高分解法。
这种比单纯取高分的更适合作者的想法，视觉推理中可能存在多条可行路径。
## 思考thinking

作者实际上做的是在共享LLM主干上增加了LVIP辅助预测头，预测正确选项图像的特征向量，并与文字推理监督联合训练。LVIP预测的向量越接近正确选项的图像向量，视觉部分的损失越小，RL中对应的视觉奖励越高。
那么实际上作者的训练目标是向量对齐，希望借此增强模型的视觉认知能力。但缺的关键一步在于 **“向量对齐有效 → 形成视觉想象或规则推演能力”** 这一步。

已有相关研究提供了不同的思路：
- CVRR：研究模型是否真正依赖（这个向量）潜在表示产生答案
- Causal-JEPA：通过对象遮挡，鼓励模型依赖上下文和对象关系进行预测（强迫模型推理）
- 反例引导学习：发现当前预测或假设的错误，利用反馈修正

所以实际上最小可做的实验是通过跨图形来检验模型的规则推理能力。
比如说我们可以这么构建：

|划分|图形|规则|
|---|---|---|
|训练集|各种箭头、三角形|顺时针旋转 90°|
|验证集|带缺口的 L 形|顺时针旋转 90°|
|测试集|新生成的不规则多边形|顺时针旋转 90°|

让模型去学会规则，而不是“预测图形”
后续尝试的方法可以是去看模型的规则迁移能力如何
然后建立假设
