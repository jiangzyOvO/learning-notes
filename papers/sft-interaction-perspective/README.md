## 研究问题是什么？为什么重要？

SFT（监督微调）通过“问题—理想回答”样本训练模型，提高它生成理想回答的概率。但同样是 SFT，效果可能不同：

- 模型更会遵循指令，输出更符合要求。
- 训练集表现提高，遇到新问题却没有进步。
- 特定任务变好，其他能力退化。
- 继续训练，收益越来越小，甚至开始变差。

因此，论文研究的问题是：**SFT 究竟通过增加、强化或删除哪些预测依赖来改变模型表现？这些变化为什么有时改善泛化，有时导致退化？**

性能改善可能来自学习新规则、强化已有规则，或减少不可靠规则的干扰。仅看最终分数，很难区分这些解释。论文尝试通过输入词之间的 **interaction（交互作用）**，追踪模型预测依赖的变化。

这个问题有三方面价值：

1. **训练决策**：什么时候继续训练，什么时候停止？
2. **数据决策**：需要继续训练已有数据，还是补充新的知识和任务覆盖？
3. **能力判断**：模型学到了新能力，还是更好地使用了已有能力？

## Intuition 与核心发现

**研究 intuition：模型表现变好，未必意味着增加了新知识，也可能来自更好地利用已有模式。因此，需要同时追踪训练过程中的“获得”与“失去”。**

在作者测试的设置中，SFT 早期会删除大量复杂、相互抵消、跨模型共享程度较低的交互，同时保留并强化部分已有交互；后期则出现更多具有上述特征的新交互。

作者将这一过程解释为：**早期主要去噪，后期主要过拟合。**

## 具体方法

作者对同一批提示词，固定待分析的词和目标 token，穷举选定词的保留／遮挡组合，并通过替换对应词的 embedding 实现遮挡。然后，使用不同训练时刻的模型 checkpoint，记录各遮挡输入下目标 token 的预测概率，并将其转换为 log-odds 分数。

接着，作者沿用已有的 [AND–OR 交互提取方法](https://arxiv.org/abs/2304.13312)，通过优化分解和容斥反演，提取各词组的 AND、OR 交互系数：

- **AND 交互**：涉及的词全部保留时生效。
- **OR 交互**：涉及的词至少保留一个时生效。

把当前输入触发的交互贡献与基线分数相加，就能重建模型在该遮挡输入上的评分。

最后，根据显著交互在不同 checkpoint 中的存在情况，将其划分为**删除、持续保留和新出现**三类，并追踪各类交互的数量、强度、阶数、跨模型共享比例 $`\gamma`$ 和未抵消比例 $`\rho`$，据此分析微调过程中预测依赖及其质量的变化。

## 攻击点

**作者把较强的正负抵消视为交互更可能属于噪声的证据，但抵消也可能承担必要的逻辑功能。**

例如，异或规则可以写成：

```math
f(A,B)=\operatorname{OR}(A,B)-\operatorname{AND}(A,B).
```

当 A、B 都为真时，OR 的 $`+1`$ 与 AND 的 $`-1`$ 正好抵消，正确输出 0；只有一个条件为真时，输出为 1。

这里两个交互系数都非零，抵消实现了“两个条件不能同时满足”的约束。因此，**净贡献为零不等于交互无用，低未抵消比例 $`\rho`$ 不能单独证明这些交互属于噪声。**

## Follow-up

**能否根据模型在新情境和反事实测试中的实际表现，判断应该停止训练，还是补充能够区分正确规则与错误捷径的数据？**

遇到新规则、新接口或新流程时，复杂或模型特有的交互可能代表必要的新学习。仅凭这些特征判断“开始过拟合”，可能阻碍真正的能力增长。

因此，可以检验模型新增的预测依赖是否满足：

- 在未见过的组合和表达方式下仍然有效；
- 改变无关信息时，答案保持稳定；
- 改变决定答案的关键条件时，答案随规则正确变化。

进一步，可以让模型提出可能的规则与能力缺口，再由程序、规则引擎或可靠标注验证，而不直接相信模型对自身能力的判断。

例如，模型可能学到了“授权有效才允许”，也可能只是依赖“出现管理员就允许”的捷径。此时，“管理员但授权已过期”和“普通用户但持有有效授权”，就是能区分两种解释的关键样本。

当训练表现停滞时，可以比较三种操作：**停止训练、继续重复原数据、加入这种针对性样本**。在相同预算下，观察针对性数据能否带来独立测试上的能力增长，从而区分“已经学够”与“缺少关键经验”。
